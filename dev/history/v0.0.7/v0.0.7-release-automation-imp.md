# MarkdownViewer v0.0.7 リリース自動化skill実装計画

対応要求: [`v0.0.7-release-automation-req.md`](./v0.0.7-release-automation-req.md)
作成日: 2026-08-10 / ステータス: **実装・非破壊検証完了**

## Phase 1: 仕様固定

- 安全な意図判定、モード、チャネル、設定項目、skill境界を文書化する。

## Phase 2: プロジェクトスクリプト汎用化

- `packaging/release-config.json`を追加する。
- App Installer生成、サイト配置、公開検証から固定version／beta URL／ファイル名を除く。
- 既存beta用script名は互換wrapperとして残す。
- stable／betaの両チャネルを同じ処理で扱えるようにする。

## Phase 3: 安全なオーケストレーター

- `Plan`、`Build`、`Stage`、`Publish`、`Verify`、`Full`を実装する。
- 既定をPlanとし、時間のかかる処理と外部変更へ二重の明示switchを要求する。
- Plan、拒否動作、設定解決を非破壊テストする。

## Phase 4: 個人skill

- 公式skill initializerで`publish-msix-release`を作る。
- `SKILL.md`、`agents/openai.yaml`、`references/release-contract.md`を実装する。
- `quick_validate.py`を実行する。
- Planと拒否動作だけでforward testする。

## Phase 5: 統合

- frontend／Rustの製品コードは変更しないため、release buildやinstaller生成は行わない。
- PowerShell syntax、設定、Plan、拒否動作、既存公開物Verify、skill validatorを実行する。
- 各フェーズをコミットし、実装報告を完成する。
