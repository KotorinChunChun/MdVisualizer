- [ ] PREVIEW03: 埋め込み画像ではパス関連の項目を無効にし、「埋め込み画像のためパスはありません」と理由を表示する。説明文が空の場合も該当コピー項目を無効にして理由を示す。

### 確定時の質問・回答と補正

| 論点 | 確定した回答・判断 |
|---|---|
| 拡張Windowsパス | 本ツールで発生しやすい表記であり、利用者向けには通常のフルパスへ変換する。履歴照合にも正規化を使う。 |
| 採用済み画像と保持期限 | 設定されたMarkdown基準の相対フォルダーへコピーする。文書側の画像を履歴削除の対象にしないため、キャッシュ内での採用済み画像の個別保護は不要。 |
| 必要な差分 | コード差分、コードをレンダリングしたビジュアル差分、画像差分の3種類。対象不明時は画像差分だけでもよい。対象確定時は全文から無関係な共通部分を隠す。 |
| Base64を使わない候補表示 | キャッシュ内のMarkdownと相対PNGで、採用後と同じコードを使用する。 |
| 画像付きMarkdownのコピー | 対象文書の設定先へ画像を配置して相対参照をコピーする。基準不明時は文書またはフォルダーを選ぶ。2026-09-29に「４提案通りでOK」と明示承認。 |
| コピー名称 | 「マークダウンでコピー」は「コードをMarkdownでコピー」とする。 |
| その他の提案 | 質問応答の挿入、共通対象判定・メニュー、キャプション生成、プレビューの追加コピー項目は上記仕様で確定。 |
