## Markdown編集画面

- ローカルMarkdown文書をアプリ内で編集し、明示的な保存操作で元ファイルへ保存できる。
- 「編集のみ」「編集／閲覧」「閲覧のみ」をボタンで切り替えられる。
- 編集／閲覧では編集中のドラフトをライブプレビューする。
- 既存のA4、A3、プレゼンテーション、画像一覧などの表示レイアウトとは独立した画面モードとする。
- 起動時と文書を開いた直後の既定は「閲覧のみ」とする。
- SharePoint文書、単体SVG、単体Mermaidは本版では閲覧専用とする。
- 未保存状態を明示し、再読み込み、タブ終了、ウィンドウ終了、外部更新による意図しない消失を防止する。
- ファイルのエンコーディング、BOM、改行コードを可能な限り維持する。

## Markdown編集操作

- 見出し、太字、斜体、取り消し線、引用、箇条書き、番号付きリスト、チェックリスト、リンク、インラインコード、コードブロック、表、Mermaid、水平線、画像、draw.io図の挿入操作を提供する。
- Markdown構文強調、見出し／フェンスの折り畳み、Base64データの折り畳みを提供する。
- `Ctrl+S`で保存できる。

## CSV／TSV

- `csv`、`tsv`、`csv-h`、`tsv-h`のコードフェンスを対話型の表として表示する。
- 検索、並べ替え、列表示、ページング、コピー、CSV出力、印刷を提供する。
- SearchPanesは各CSV／TSV表の初期表示で必ずOFFとする。
- SearchPanesは利用者が明示的にONへ切り替えられる。
- 表編集画面から行、列、セルを編集し、対象コードフェンスだけをドラフトへ反映する。

## SVG

- SVGをMarkdown内のXML埋め込み、またはMarkdownと同じフォルダの別ファイルとして扱える。
- SVG編集画面に「埋め込みへ変換」「外部ファイルへ変換」を設ける。
- 変換は選択した出現箇所だけを更新する。
- 外部ファイルから埋め込みへ変換しても、元ファイルは自動削除しない。
- インラインSVGは危険なスクリプト、イベント属性、外部参照を実行しない。

## ラスタ画像

- ラスタ画像をBase64 Data URI埋め込み、またはMarkdownと同じフォルダの別ファイルとして扱える。
- 画像編集画面に「埋め込みへ変換」「外部ファイルへ変換」を設ける。
- Base64画像と外部画像の双方で編集機能を利用できる。
- 鉛筆、ブラシ、消しゴム、塗りつぶし、スポイト、線、矢印、図形、文字、切り抜き、回転、反転、サイズ変更、Undo／Redoを提供する。
- 既存の外部画像編集ではバックアップと外部変更検出を維持する。

## draw.io

- `drawio`コードフェンスを図として表示する。
- draw.io図を新規作成し、既存図を再編集できる。
- `mxGraphModel`、`mxfile`、既存の圧縮diagramデータを扱う。
- diagrams.netの埋め込みエディターとの通信は送信元とメッセージ形式を検証する。
- 保存時は対象コードフェンスだけをドラフトへ反映し、キャンセル時は変更しない。
- SVGおよびMermaidからdraw.io図への変換を提供し、変換できない要素を利用者へ通知する。
- ネットワークまたはエディターの読込みに失敗した場合は、文書を変更せずエラーを表示する。

## 保存と競合保護

- Markdown保存は一時ファイルを利用して原子的に置換する。
- 読込み後に外部更新された文書を確認なしで上書きしない。
- SVG／画像の外部ファイル化はMarkdown保存が成立するまで一時領域に保持し、失敗時に不完全な参照を残さない。
- 同名ファイルが存在する場合は上書きせず、衝突しないファイル名を生成する。

## spmd画像の読込み

- `spmd:`で開いたSharePoint Markdown文書から参照されるPNGとSVGをMicrosoft Graph経由で認証取得し、本文内へ表示できる。
- Markdown文書と同じSharePointサイトおよびドキュメントライブラリ内の相対参照だけを許可し、別テナントや未検証URLへ認証情報を送信しない。
- アクセストークンを画像URL、Markdown、DOM、ログへ埋め込まない。
- PNGは実データ形式とサイズを検証し、SVGはスクリプト、イベント属性、外部参照などを除去してから表示する。
- 文書再読込み時は画像も再取得し、認証切れの場合は保存済み更新トークンによる自動更新を利用する。

## spmd画像編集と保存

- `spmd:`文書から読み込んだPNGを既存のラスタ画像編集画面で編集し、編集結果をPNGとして元のSharePointファイルへ保存できる。
- `spmd:`文書から読み込んだSVGを編集対象として扱い、編集結果を安全化したSVGとして元のSharePointファイルへ保存できる。
- 保存先は選択した画像が存在する同じSharePointサイト、ドキュメントライブラリ、ファイルパスに限定する。
- 読込み後に外部更新された画像を上書きしないよう、eTagによる競合検出を行う。
- 保存失敗、認証失敗、競合検出時に元ファイルを変更せず、利用者へ理由を表示する。
- SharePoint側のバージョン履歴を利用し、ローカル画像用の独自バックアップ処理は適用しない。

## SharePoint操作とUIフィードバックの改善

- SharePoint画像の編集可否を、委任スコープと対象DriveItemの実効権限から保存前に判定する。
- 書込み権限がない、または安全に確認できない画像の編集ボタンは無効化し、ツールチップで理由と対処方法を案内する。
- Microsoft Graphの保存失敗では、HTTPステータス、Graphエラーコード、request-idを含む診断可能なメッセージを表示する。
- 画面右下の通知はフェード開始まで3秒間表示する。
- タブの右クリックメニューはコマンド選択後に閉じ、成功または失敗の結果を画面右下へ表示する。
- 既にアプリが起動している状態から追加で開いたウィンドウを前面へ表示する。
- `spmd:`文書内のMarkdown以外の相対リンクは、同じSharePoint上のHTTPS絶対URLへ変換して既定ブラウザーで開く。
- タブの「SharePointで開く」は、対象ファイルを選択したドキュメントライブラリの`Forms/AllItems.aspx`を、`id`と`parent`付きで開く。

## spmd Markdown本文編集

- `spmd:`で開いたMarkdown本文を「編集のみ」と「編集／閲覧」で編集できる。
- 保存時はMicrosoft Graphで元のSharePoint Markdownファイルを更新する。
- 読込み後に外部更新された本文を上書きしないよう、eTagと`If-Match`で競合を保護する。
- 元文書の文字コード、BOM、改行コードを可能な限り維持する。
- 保存失敗時は編集内容を残し、HTTPステータス、Graphエラーコード、request-idを表示する。
- 編集画面の3つの切替ボタンは一体のセグメントコントロールとして表示し、選択中を明確にする。
- 文書操作の「再読み込み」は「再読込」へ改称する。

## 本版の対象外
- PNGとSVG以外のSharePoint画像形式の編集保存。
- 別テナント、別サイト、別ライブラリへの画像移動またはコピー。
- Markdown内の任意JavaScript付きHTML文書の実行。
- 外部ファイルを埋め込みへ変換した後の元ファイル自動削除。
- v0.0.9配布物のインストール。

## デスクトップ版・SPFx版の統合出力

- 本リポジトリからRust＋Tauriのデスクトップ版Markdown Editorと、SharePoint Online向けSPFx Markdown Editorの両方を生成できる。
- SPFx版はSPFx 1.23.2、Node.js 22、TypeScript 5.8、Heftを使用し、通常Web PartとSharePointフルページの両方に対応する。
- デスクトップ版とSPFx版のUI実装は分離し、Markdown構文、編集操作、リンク解決、サニタイズ方針、互換テストを共通仕様とする。
- Markdown解析はUnified／remark／rehype系、編集面はCodeMirror 6へ統一し、参照SPFx実装のMarkedとCodeMirror 5は採用しない。
- SPFx版は`SPHttpClient`で利用者本人のSharePoint権限を使用し、デスクトップ版はMicrosoft Graphを使用する。両者をストレージアダプターとして分離する。
- SharePoint保存はeTagと`If-Match`で競合を保護し、元文書の文字コード、BOM、改行コードを可能な限り維持する。
- SPFx版のファイル選択は文書ライブラリとサブフォルダーを列挙し、`.md`と`.markdown`を対象にする。
- 既存SPFxパッケージのsolution ID `cc592ba5-ad2e-4616-ba55-5c9cc000a6ab`、Web Part ID `b4752ea8-2872-48e9-8027-2acee063cc51`、Feature ID `21be68cf-476f-4fcd-9b1e-449b3d855ad4`を継承し、既存アプリを上書き更新する。
- SPFxのパッケージ版はデスクトップ版を基準とし、デスクトップ版`0.0.9`をSPFxでは`0.0.9.0`として出力する。
- 通常のSPFxビルド成功後は既存App Catalogへsppkgをアップロードして更新する。SharePointを変更しない確認用に`-SkipUpload`を用意する。
- CLI用MarkdownViewerアプリへSharePoint委任`AllSites.FullControl`を構成し、テナント管理者の同意後にCLIを再認証する。
- SPFxパッケージは全サイトで使用可能な構成とし、通常のSPFxビルド成功後に上書きアップロードと全サイトへの自動展開まで実行する。
- デスクトップ版のdraw.io接続先は公式`embed.diagrams.net`に固定する。
- SPFx版のdraw.io接続先は公式diagrams.net、自社ホスト、指定した同一SharePointサイトから選択できる。接続先ごとのオリジン検証を行う。
