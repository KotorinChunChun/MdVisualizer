# AIによる文章・画像・図の相談と編集

Windowsデスクトップ版の任意機能です。SPFxには含みません。通常の閲覧・編集にはCodexの導入もログインも不要です。スキルの作成・対象設定は[AIスキルの設定](/docs/user/ui/codex-skills.md)を参照してください。

## 有効化

1. 利用する場合だけ[公式Codex CLI](https://github.com/openai/codex)を導入する。CLI 0.153.4で検証済み。
2. 外部のPowerShellで `codex login` を実行し、利用者自身でログインする。
3. MdVisualizer上部の「AI」を開く。
4. 指示文の下のツールで「Codex CLI」を選ぶ。MdVisualizerはPATHを優先し、次に公式Windowsインストーラーのユーザー領域から `codex.exe` を自動検出する。
5. モデルを確認する。初期値は `gpt-5.6-luna` です。初めて送信するとき、サブスクリプションのクレジットを消費する旨の確認が表示されます。同意して設定の保存に成功した場合だけ送信し、次回からは確認を省略します。キャンセルでは指示と添付を保持します。

CLIを自動インストールしたり、ユーザーのCodex全体の設定を書き換えたりしません。検出できない場合は、Codexの導入後にPATHを更新してMdVisualizerを再起動してください。モデルの利用可否・利用上限はログインしたアカウントに従います。

## 使い方

- ローカルMarkdownを開いて「AI」を押します。閲覧のみでも表示モードを維持して相談・編集案の採用を行えます。
- パネルの「選択テキストを追加」で現在の選択範囲を取り込みます。対象がない場合は文書全体を対象にします。
- 指示を入力して「送信」またはCtrl+Enterを押します。Enterだけなら改行します。
- 右クリックで対象部分を選ぶと、その対象で利用可能なスキルを選べます。画像の解説・文字起こし・編集は直接新しい会話を準備します。「この画像をAIの送信対象に追加」は現在の会話へ添付します。自動送信はしません。
- 会話中に画像を追加すると、パネル内で `画像1`、`画像2` のように番号が付きます。番号と添付内容は会話履歴にも保持されます。
- 「停止」で生成を止めます。停止後に到着した回答や、対象文書が変わった古い回答は採用できません。

生成は通常120秒、PNG画像の生成・編集は300秒でタイムアウトします。「AIに画像の編集を依頼」の指示欄には既定指示を表示し、編集と「既定の指示に戻す」ができます。「新規画像を生成」では元画像なしで候補を作れます。

生成画像はまず未採用の候補として会話へ保存されます。応答画像の「画像差分を確認」から、左右・上下・重ね合わせ・変更箇所の強調を選べます。形式と元の寸法を表示し、大きな画像の画素比較は長辺1600pxへ縮小して行うことを画面内に示します。

採用時のファイル画像は、設定のMarkdown基準の相対フォルダーへ別名コピーします。「文書と同じ場所」「固定ファイル名」の設定は文書フォルダー、それ以外は `image/` を使います。既存ファイルは上書きしません。埋め込み画像の置換はデータURIを更新します。未保存文書では先にMarkdownの保存先を選びます。採用した画像は履歴の保持期限で消えません。

## 会話履歴

パネル上部の「会話履歴」には保存済みの会話が一覧表示されます。一覧で会話を選ぶと、送信内容、回答、添付画像をプレビューできます。「この会話を開く」で会話を再開し、未採用候補の比較と採用も再開できます。元画像・応答画像・対象・採用状態・反映先を保持します。通常のWindowsフルパスで表示し、拡張形式のパスも同じ文書として照合します。会話をプレビューしただけでは最終会話日時は変わりません。

「この会話を削除」で選択した会話と添付を削除できます。現在開いている会話を削除すると、空の新しい会話へ切り替わります。Escで履歴を閉じます。画像を拡大している場合は、最初のEscで拡大表示だけを閉じます。

保持日数の初期値は30日です。保持日数を短くすると、その時点の期限を過ぎた会話と通信ログを直ちに削除します。0日にすると履歴と下書きを消去し、以後保存しません。設定できる範囲は0〜3650日です。

履歴の会話は最大20往復（送信・回答のメッセージ最大40件）を送信に利用します。送信量は指示、対象本文、履歴本文の合計120,000 UTF-8 bytesまでです。添付画像は最大12枚、送信するbase64データの合計40,000,000 bytesまでで、復号後の1枚あたりの画像データは10MB以下です。

履歴一覧に表示される「キャッシュを利用できない可能性があります」という案内は、最終会話から1時間以上経過した場合に表示されます。1時間を境にキャッシュの有無を断定するものではありません。Codex CLIが返した直近の入力トークン数は、取得できた場合だけ表示します。文字数からトークン数を推定しません。

## 変更案の確認

編集案は大きなプレビューで現在の内容と提案内容を確認できます。図などのプレビューがある場合、初期状態ではコード差分を折りたたみ、プレビューを表示します。「コード差分を表示」から行単位の差分と編集欄を開けます。コード差分を表示した状態では、変更前後のプレビューを左右50:50で表示し、「左右配置」「上下配置」で切り替えられます。

行ごとに「変更前へ戻す」「生成案を再採用」を選べます。コード差分の「変更後のコード全文を直接編集」を開くと、変更後を直接編集できます。「決定」を押すまで本文や文書側の画像ファイルは変更されません。「却下」で候補を却下し、閉じる操作では確認画面を閉じます。未採用候補は会話から再び確認できます。採用後は通常の保存操作でMarkdownへ保存します。

「質問」の回答を含め、応答の「挿入」から「前に挿入」「置換」「後に挿入」「カーソル位置に挿入」「コピー」を選べます。前後は対象の開始行・終了行を基準とし、対象を指定しなかった場合は文書全体を基準にします。置換は選択文字列・対象画像・対象ブロックそのものに適用します。対象未指定では全文を置換し、確認画面に「全文置換」と明示します。カーソルは操作を選んだ時点の位置です。コピーはMarkdownで行い、画像を伴う場合は先に実ファイルを配置してから参照コードをコピーします。

コードとビジュアルの比較は変更部分を含むブロックを表示し、無関係な共通部分を折り畳みます。表・リスト・フェンスは途中で切りません。全文表示とBase64の展開も選べます。確認中に本文が変わると反映を止めます。画像だけの比較から挿入方法を選んだ場合も、コード・ビジュアルの確認後に決定します。

## 右クリックから対象部分について相談する

閲覧側の通常テキスト、コードブロック、Mermaid、draw.io、SVG、画像を右クリックすると、対象に応じたスキルが表示されます。画像の解説・通常文字起こし・表文字起こしは画像の右クリックメニューから選びます。SVG、Mermaid、draw.ioでは既定のOCRを表示せず、解説や図の改善を選びます。画像解説と文字起こしの結果は、可視化後の画像を根拠にします。

コードとビジュアルは同じ対象判定とメニューを使います。ラスタ画像では「図としてコピー」「コードをMarkdownでコピー」、区切り、格納形態変換、区切り、AI操作の順です。「AIでキャプション生成」は選択した画像の説明文だけを差分確認します。コードフェンス内の画像らしい文字列は画像として扱いません。切り取り・貼り付け・全選択は従来のキーボード操作で利用できます。

閲覧側で文字を選択している場合は、選択した連続範囲をMarkdownソースの行範囲へ対応付けます。対応が一意に決まらない場合は推測しません。選択していない場合は右クリックした段落またはブロック全体を対象にします。パネルには対象本文と位置を表示します。

編集の許可は次の3択です。

| 選択肢 | 送信・適用範囲 |
| --- | --- |
| 質問のみ | 対象部分について回答します。応答の「挿入」から内容を確認して適用できます |
| 指定場所のみ編集 | 取り込んだ範囲だけを置換します |
| 全文から編集 | 指定部分を中心に同じ文書の全文を検討・変更します |

## 通信ログ

パネル上部の「通信記録」には、CLIへ渡した利用者指示・制御指示・設定・入力データ・画像と、CLIからのJSONLイベント・応答画像・標準エラーを表示します。成功だけでなく、失敗・停止・タイムアウトまでに受け取ったデータも確認できます。これはアプリが観測したCLI入出力であり、CLI内部のサービス通信は取得していません。

送受信画像はサムネイルから拡大できます。Base64は初期状態で折り畳み、「生データを表示」で確認できます。「生データをコピー」「JSONを書き出す」も使えます。要求IDで会話の候補状態と対応付け、認証値は記録対象から除外します。

ログの保持件数は1〜1,000件で、初期値は20件です。会話保持日数を変更すると、通信ログにも同じ期限が適用されます。共有端末では送信本文が保存されることを考慮し、利用後にアプリのローカルデータを適切に管理してください。CLIが使用量を返した場合だけ、その通信の入力・出力トークンを表示します。

## パネルの幅と範囲

「新しい会話を開始」の左のトグルで最大化し、再度押すと元の幅へ戻せます。会話や入力は維持します。AIパネル左端をドラッグするか、幅変更のseparatorへフォーカスして左右矢印キーを押すと幅を変更できます。狭い幅でも操作を折り返して表示します。変更案プレビューは左右または上下を選べます。

最上部に「新しい会話を開始」、その下に「会話ログ」、指示文、左右に並ぶツールとモデル、次回送信する対象・添付を配置しています。ログと指示文の境界はドラッグ、またはフォーカス後の上下矢印キーで調整できます。指示文の右に送信と停止、その下に編集モードの選択肢があり、送信中は状態表示と回転マークを表示します。

テキストと画像は複数追加でき、既定名は「テキスト1」「画像1」です。一覧の名前欄で変更し、指示文からその名前で参照できます。各項目の「外す」は次の送信対象だけを解除し、元文書・元画像・送信済み履歴を変更しません。複数テキストの質問では選択した抜粋だけを送り、複数範囲の編集では全文の差分を確認します。「指定場所のみ編集」では範囲外の変更を採用できず、「全文から編集」では全文を編集対象にします。

送信成功後は指示文と入力側の対象・添付を空にし、送った本文・画像を会話ログに残します。停止や失敗では再送用の下書きを保持します。通常の文章送信後は質問モードへ戻り、次回の編集対象と許可を改めて選べます。PNG生成後も採用前の画像比較は残します。

ツールはCodex CLIを利用できます。ChatGPT API、Claude CLI／API、Copilot CLI、Copilot Chat CLIは未実装の候補として表示し、選択しても送信できません。モデルは候補から選択するか名前を入力し、変更した場合は「設定を保存」で反映します。

元文書のファイルパスをCLIへ渡さず、一時作業領域で文章生成を行います。シェル・ブラウザー・プラグイン等を無効化し、元ファイルへの直接編集を許可しません。回答生成のタイムアウトは120秒、PNG画像編集は300秒です。

会話履歴と下書きは、閉じる、文書切り替え、再読み込み、アプリ終了だけで直ちに消えるものではありません。保持日数の期限、0日設定、または利用者の削除操作に従って保存・削除されます。

## 初期版の範囲

ローカルMarkdownの全文／選択範囲、画像、SVG・draw.io・Mermaidの図の相談と書き換え、PNG画像編集が対象です。SharePoint文書、SPFx、複数ファイルの自律編集、公式Codexアプリの会話同期は対象外です。Codex CLI以外のAI実行機能やClaudeの実行機能を再現しません。
