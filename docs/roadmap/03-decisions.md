## 1. ウィザードで確定した事項

| ID | 項目 | 決定 | 設計への影響 |
| --- | --- | --- | --- |
| D-01 | 対象ユーザー | Windowsデスクトップ利用者とSPFx利用者を同格に扱う | 共通ドメイン契約と能力マトリクスを必須化 |
| D-02 | ライセンス | MIT License | LICENSE、著作権表記、第三者ライセンス管理を追加 |
| D-03 | セキュリティ | 一般企業利用水準 | 最小権限、CSP、秘密保護、監査可能なエラーを必須化 |
| D-04 | データ正本 | ローカル／SharePointファイルが正本、SQLiteは補助情報のみ | 本文はDBへ恒久保存しない |
| D-05 | オンライン同期 | SharePointバックグラウンド同期 | v0.0.15でキュー・競合・再試行を実装 |
| D-06 | AI接続 | APIキー方式＋Claude CLI/Codex CLI等のCLI方式 | 共通AI providerと能力検出が必要 |
| D-07 | AI機能 | 校正、要約、QA、構成、生成、診断、複数文書、直接編集 | 段階提供、共通提案モデルが必要 |
| D-08 | AI編集権限 | ファイル単位のDiff承認後に保存 | AIは元ファイルを直接変更しない |
| D-09 | クラウド | SharePoint、diagrams.net、利用者設定AI APIのみ。運営クラウド・利用統計なし | ネットワーク許可先と送信前表示が必要 |
| D-10 | プラグイン | 内部拡張ポイントのみ | 第三者コード読み込みは対象外 |
| D-11 | OS | デスクトップはWindows専用 | Windows固有アダプターを明示し他OS対応はしない |
| D-12 | モバイル | SPFxのレスポンシブ閲覧・簡易編集 | タッチ・狭幅・アクセシビリティを共通受入へ追加 |
| D-13 | 次リリース | v0.0.14は品質・アーキテクチャ基盤 | 同期・AI本体は後続版 |

## 2. 過去方針との衝突

`dev/PLAN_REJECT.md`の次の記述は、今回の確定判断により`SUPERSEDED`となる。

- Markdown本文の編集を永久対象外とする記述
- クラウドストレージやアカウント同期を永久対象外とする記述

履歴は削除せず、判断日と置換先を追記する。旧文書を機械的に次版要求へ戻さないという運用方針自体は維持する。

## 4. 実装開始前に追加確認が必要な条件

- AI APIへ送ることが許される文書区分と、送信前確認画面の必須項目
- SharePoint同期でオフライン編集を許すか、閲覧キャッシュだけにするか
- 組織管理AIエンドポイントを将来許可するか
- SPFxモバイル簡易編集に含める編集機能の上限

これらはv0.0.14の基盤実装を妨げない。該当する後続設計のDefinition of Readyに組み込む。
