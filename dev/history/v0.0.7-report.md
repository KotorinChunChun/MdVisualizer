## 2. セキュリティと安全性

- Markdown中のPowerShellは自動実行せず、コード、作業ディレクトリ、制限を示した確認操作を実行ごとに要求する。
- 実行対象は保存済みの`.md`／`.markdown`文書と明示された3言語に限定する。
- stdoutとstderrを同時に回収し、timeout、出力上限、二重実行防止を設ける。
- 色設定は安全な16進色、フォントは固定選択肢だけを受け付け、任意CSSは挿入しない。
- 検索結果、実行出力、設定値はReactのテキストとして表示し、HTMLとして再解釈しない。

## 4. GUI受入

この実装ターンではGUI自動操作を実施していない。リポジトリ規則に従い、実施する場合は
アプリ表示後の5秒間に人間のマウス・キーボード入力を監視し、入力がない場合だけ操作を開始する。

手動確認には`samples/v0.0.7-customization.md`を使用できる。GUI受入後は、単一パネルの
3タブ、`Ctrl+F`、画像ジャンプ、配色設定、確認付きPowerShell実行、印刷プレビューの設定反映を確認する。
