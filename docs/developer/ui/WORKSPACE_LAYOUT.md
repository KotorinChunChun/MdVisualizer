# ワークスペースの配置

Desktop と HTML/PHP Web の文書ワークスペースは、利用できる機能の範囲で同じ操作の相対順序を使う。全操作の登録と名称・順序の検査は [UI_COMMAND_MATRIX.tsv](/docs/developer/ui/UI_COMMAND_MATRIX.tsv) を正本とする。コードブロック、埋め込みファイル、図、表の周辺メニューを変更するときは、まず [ブロックUI仕様](/docs/developer/ui/BLOCK_UI_SPEC.md) を確認する。

## メインツールバー

Desktop は「新規MD、開く、印刷、HTML出力、診断、再読込、保存、コード、プレビュー三択、差分、分割方向、外部操作」の順で置く。Web は「開く、印刷、HTML出力、保存、コード、プレビュー三択、差分、分割方向」の関係を維持し、右端を「下書きを削除、ファイル名、オプション開閉」の順にする。Web のファイル名はダブルクリックでブラウザー内の編集中の名前を変更できる。この名前変更はダウンロード時の名前へ反映され、サーバーへ自動保存しない。

コードは独立した ON/OFF、プレビューは「OFF、プレビュー限定、ビジュアル編集」の三択である。分割方向は「自動分割、上下分割、左右分割」で、本文レイアウトとは別に扱う。選択状態は Desktop と Web で共通のアクセント色を使い、プレビュー限定は中間色で区別する。

## プレビューとフッター

プレビューパネル上端には、見出し操作とレイアウトを置く。本文の余白・ズーム・スクロール領域とは分離し、操作バーは本文の兄弟要素として固定する。レイアウトは「オート、A4縦、A3縦、プレゼン、画像中心」で、Web の旧プレゼン単独ボタンは置かない。目次、検索、画像はワークスペース左端の縦ツールバーから開く。コードのみ・分割表示でも縦ツールバーを維持する。検索欄は狭幅でもオプションメニューへ移さない。

Desktop のフッターは文字コードなどの文書状態、テーマ、Auto Reload、Zoom、編集テスト、ショートカット、設定を提供する。Web は文字コードと BOM を左端に置き、右側を「テーマ、Zoom、ショートカット、設定」とする。Web のテーマ・Zoom・設定はブラウザー画面内の表示用であり、PHP のサーバーへ自動保存しない。Auto Reload と編集テストは Web に置かない。

## 実装上の注意

非対応のホスト機能は空白のボタンを作らず省略する。外部アプリ起動、フォルダー、VS Code、PowerShell 実行などは Desktop 固有である。Web のファイル操作はブラウザーの選択・ダウンロードであり、ローカルパスへの直接書き込みは行わない。

## ビジュアル編集の直接操作

ビジュアル編集では、本文のテキストをダブルクリックして編集する。長い段落の入力欄は折り返し後の本文量に応じて高さを広げ、画面の65%を上限に欄内をスクロールする。チェックリストのチェックボックスはクリックで切り替える。プレビュー限定では本文を変更しない。

Desktopでは本文をマウスで5px以上ドラッグすると同じ階層の段落・リスト項目などを移動できる。挿入位置は青い線で示し、Escまたは操作の中断で取り消す。表やコードの構造を壊さないよう、Markdownとして安全に移動できる単位で処理する。Webの長押し移動は従来どおり使える。
