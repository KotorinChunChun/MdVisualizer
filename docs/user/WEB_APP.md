# MdVisualizer Web版

Web版の正本は子リポジトリ `web-platform` にあります。HTML版とPHP版は `apps/web` を共有し、PHP版のログインはサイト共通SSOを使用します。

## PCでローカルHTMLを開く

ビルド成果物の`mdvisualizer.html`をブラウザーで開きます。ローカルサーバー、PHP、Pythonの起動は不要です。MarkdownまたはZIPをドラッグ＆ドロップするか、「開く」から選択してください。ZIPのフォルダー階層と画像・外部図を保持して編集します。

関連ファイルがない文書は「保存」でMarkdownをダウンロードします。画像などの関連ファイルがある文書は「ZIPを保存」となり、Ctrl+Sも文書と資産をまとめて保存します。「本文のみ保存」はMarkdownだけを取り出す操作です。ブラウザーの設定によって、保存先を尋ねるかダウンロードフォルダーへ保存します。UTF-8、BOM付きUTF-8、UTF-16、Shift_JISの読込・保存に対応します。Shift_JISに変換できない文字を追加した場合は、UTF-8へ切り替えて保存してください。

ソース・プレビュー・分割表示、本文の直接編集、表編集、Mermaid GUI、draw.io、画像編集、差分比較、プレゼンテーション、HTML出力を使用できます。Web版は単一文書を扱い、デスクトップの複数タブ・外部アプリ起動・PowerShell実行・ローカルファイル監視・Codex連携は提供しません。

Mermaidの「編集」からノードを選び、表示文字・形・色・接続等を変更できます。エディター内の変更を終えたら、外側の「反映」でMarkdownへ戻します。draw.ioの編集は外部の`embed.diagrams.net`へ接続し、図データを渡して行います。

目次・検索・画像一覧はプレビュー左端の縦ツールバーから開きます。上部には見出し操作とレイアウト（オート・A4縦・A3縦・プレゼン・画像中心）があります。本文のダブルクリック編集は表示領域の幅を使い、表セルではセルの幅に収めます。

上部右端は下書き削除・ファイル名・オプション開閉です。ファイル名のダブルクリックで名前を入力し、Enterで保存時の名前を変更します。Escまたは欄の外へ移動すると取り消します。下部左端に文字コードとBOM、右側にテーマ・ズーム・ショートカット・設定があります。

## 下書きの復旧

本文と関連資産はブラウザー内のIndexedDBへ復旧用の下書きとして保存します。次に開いたとき、残っている下書きを復元できます。ダウンロード済みの原本やサーバーを自動更新する機能ではありません。プライベートブラウズ、ブラウザーデータの削除、保存容量の不足などでは復旧できないため、必要な成果はMD/ZIPとしてダウンロードしてください。

「下書きを削除」で復旧用データを消去できます。編集中の画面は保持し、次の編集から下書き保存を再開します。未保存の変更がある状態で別のファイルや保管データを開く場合は、置き換えの確認を表示します。

図や表の本文埋め込み・外部ファイル化、ZIP内の関連ファイル名変更にも対応します。別のMarkdownから同じ資産が参照されている場合は、リンクを壊さないため名前変更を拒否します。

## PHP版での一時保管

PHP版はHTTPSで配信し、サイト共通SSOでサインインした後に編集画面を開きます。公開された単一HTML版もスマートフォンで利用できます。HTML版はサインイン不要です。端末にダウンロードしたHTMLの直接起動は、OSやブラウザーのファイル取扱いに依存します。

## スマートフォンでの操作

最初は「プレビュー限定」を表示します。「コード」は独立したON/OFF、プレビューはOFF／プレビュー限定／ビジュアル編集の三択です。両方OFFにはできません。分割方向は自動分割／上下分割／左右分割を選べます。狭い画面では上部右端のオプション開閉で、開く・印刷・HTML出力・保存・表示切替・差分を展開します。資産がある場合はZIP保存と本文のみ保存を使えます。コード編集の「書式」には書式・図や画像の挿入・折畳・展開があります。保存は上部の操作またはCtrl+Sを使用します。PHP版の保管操作は「暗号化一時保管」を開きます。コード画面はブラウザーの表示高に追従します。

図や表の編集・折り返しは、利用できる場合には幅にかかわらず表示します。コピーは通常幅では「コピー▽」、非常に狭い場合は「…」の中に候補が並びます。十分広い場合だけコピー候補を個別に表示します。通常のMarkdown表でも検索・列表示・スライサーが使えます。表編集画面のCtrl+Aは、単一セルならセル内の文字列、複数セルを選択中なら表全体を選択します。

プレビューの本文を約0.5秒長押しすると移動対象を選択します。そのまま上下へスワイプすると青い挿入線が現れ、指を離すと移動します。通常のスクロールでは移動しません。長押し後の「上へ移動」「下へ移動」も利用でき、「移動を取消」またはEscで中止できます。直後は「行移動を元に戻す」で復元できます。

キーボードではTabで本文の移動対象にフォーカスし、Alt＋↑／↓で並べ替えます。

移動単位は段落・見出し・コード・図・表などのまとまりです。表示上の折り返し行は分割しません。リスト項目は子項目を含めて同じリスト内、表の本文行は同じ表内で動かします。表の見出しと区切り線は分離しません。HTMLや参照定義などの境界をまたぐ移動は行いません。本文編集は引き続きソース表示やプレビューのダブルタップ編集から使えます。

GoogleまたはMicrosoftでサインインし、「現在の文書と画像を一時保管」を選ぶと、指定したパスワードでブラウザー内暗号化したZIPを送信します。パスワードはサーバーへ送信・保存しません。取得時には同じパスワードを入力します。忘れた場合の復元機能はありません。

保管期間は10日です。10日を過ぎると取得できず、次のアプリアクセス時に削除されます。アクセスがなければ暗号化ZIPがサーバーに残る場合があります。自動アップロード・定期バックアップ・クラウド同期は行いません。Google Drive/OneDriveへの直接接続は将来対応です。

既定の上限は、ZIP入力32 MiB、本文8 MiB、資産単体32 MiB、展開後合計128 MiB、ZIP内1,000項目です。サーバー保管は1利用者20件・100 MiB、全体1 GiBで、管理者が変更できます。

## HTMLとして持ち出す

「HTML出力」から「スクリプトなし」または「スクリプトあり」を選び、ファイル名を指定します。出力には本文・表の全行列・画像・図を含めます。スクリプトありでは目次、コピー、図の拡大、表の検索・並べ替えが利用できます。元Markdownの任意スクリプトは出力しません。

図の生成後のHTMLは元ファイルや描画ライブラリを参照せずに閲覧できます。draw.ioを含む生成処理には、描画用の外部ライブラリ取得が必要です。外部画像はブラウザーのCORS制約により取得できない場合があります。
