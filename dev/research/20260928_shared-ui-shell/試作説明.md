# 共通フルUIの動的構成試作

2026-09-28。版を指定しない外見の検討用。製品版の変更・公開は含まない。

## 目的と構成

デスクトップ版の配置を基にした単一の `shell.tsx` から、環境プロファイルに応じてデスクトップ・Web・SPFx向けの外見を生成する。生成器は同じJavaScript・CSSを3ファイルへ埋め込み、初期環境だけを変更する。画面上でも環境を切り替えられる。

- 製品の `WorkspaceViewControls`、`StatusBar`、`DocumentSidePanel` を直接利用する。
- 共通正本の `app.css`、`content.css`、`themes.css` を利用する。
- タブの外枠、文書操作列はデスクトップの配置を参考に試作用として組み立てた。`App.tsx` 全体を自動解析・変換する実装ではない。
- 環境差は `profiles` に集約。OS機能・AI・再読込の表示を切り替える。ここでの能力設定は提案であり、各製品の対応機能を確定するものではない。
- 編集領域とプレビュー本文・図・ブロックメニューは固定サンプル。製品のMarkdownエディター／レンダラーや全メニューを移植したものではない。
- OS・認証・ファイル保存・SharePointへの接続、外部通信、利用者設定の書き換えは行わない。未接続の操作は案内を表示する。
- 画面幅・テーマ・コード／ビジュアル・分割方向・目次等・AI欄・閲覧権限の切り替えは試作内で動作する。

## 生成・確認

プロジェクトに導入済みのNode.js依存を利用する。新たなパッケージのインストールは不要。

```powershell
cd C:\develop\MdVisualizer
node dev/research/20260928_shared-ui-shell/build.mjs
node dev/research/20260928_shared-ui-shell/check.mjs
Start-Process ./dev/research/20260928_shared-ui-shell/dist/desktop.html
```

`dist/desktop.html`、`dist/web.html`、`dist/spfx.html` を生成する。依存とCSSを内包し、ネット接続なしで開ける。生成物はGit対象外。製品デバッグアプリの起動は不要。

## 次の判断

外見を確認して採用する場合は、共通シェルの製品配置、ホスト接続API、権限・機能表を定義する。現在のデスクトップ `App.tsx` もそのシェルを利用するよう段階移行する。試作を作ったことを製品UIの共通化完了とは扱わない。
