この文書は、最近追加した検索結果パネル、標準レイアウトの目次、表示倍率、別窓、
VS Codeワークスペース推定をまとめて確認するためのサンプルです。

## 確認手順

1. 標準レイアウトで目次ボタンを開き、この見出し階層が表示されることを確認します。
2. `Ctrl+F`で「回帰確認」を検索し、複数結果が左側の検索結果パネルへ表示されることを確認します。
3. `Ctrl`を押しながらマウスホイールを操作し、10%単位で倍率が変わることを確認します。
4. 「その他」を開き、ツールバーの高さが変わらないことを確認します。
5. 「別窓で開く」を実行し、同じ大きさのウィンドウが右側、収まらない場合は左側に開くことを確認します。
6. 「VS Codeで開く」を実行し、このファイルの親ではなくリポジトリルートがワークスペースになることを確認します。

## 表示倍率

倍率を50%、100%、150%、200%へ切り替え、本文、見出し、表、画像を含むプレビュー全体が
同じ比率で変化することを確認します。

| 倍率 | 期待結果 |
| :--- | :--- |
| 50% | 広い範囲が表示される |
| 100% | 基準サイズになる |
| 150% | 本文とUI内プレビュー要素が拡大される |
| 200% | 最大倍率で表示される |

回帰確認キーワードの4件目です。
