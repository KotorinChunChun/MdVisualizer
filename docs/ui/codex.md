# Codexによる文章・画像・図の相談と編集

Windowsデスクトップ版の任意機能です。SPFxには含みません。通常の閲覧・編集にはCodexの導入もログインも不要です。スキルの作成・対象設定は[Codexスキルの設定](codex-skills.md)を参照してください。

## 有効化

1. 利用する場合だけ[公式Codex CLI](https://github.com/openai/codex)を導入する。CLI 0.153.4で検証済み。
2. 外部のPowerShellで `codex login` を実行し、利用者自身でログインする。
3. MdVisualizer上部の「Codex」を開く。
4. 「Codex連携を有効にする」をチェックする。MdVisualizerはPATHを優先し、次に公式Windowsインストーラーのユーザー領域から `codex.exe` を自動検出する。
5. モデルを確認して「連携設定を保存」を押す。初期値は `gpt-5.6-luna` です。

CLIを自動インストールしたり、ユーザーのCodex全体の設定を書き換えたりしません。検出できない場合は、Codexの導入後にPATHを更新してMdVisualizerを再起動してください。モデルの利用可否・利用上限はログインしたアカウントに従います。

## 使い方

- ローカルMarkdownを開いて「Codex」を押します。閲覧のみの場合は編集／閲覧画面へ切り替わります。
- パネルの「対象テキストを取り込む」で現在の選択範囲を取り込みます。対象がない場合は文書全体を対象にします。
- 指示を入力して「送信」またはCtrl+Enterを押します。Enterだけなら改行します。
- 右クリックで対象部分を選ぶと、その対象で利用可能なスキルを選べます。「現在の会話に追加」または「新しい会話を開始」を選んでから送信します。
- 会話中に画像を追加すると、パネル内で `画像1`、`画像2` のように番号が付きます。番号と添付内容は会話履歴にも保持されます。
- 「停止」で生成を止めます。停止後に到着した回答や、対象文書が変わった古い回答は採用できません。

生成は通常120秒でタイムアウトします。PNG画像編集は画像生成処理を含むため300秒でタイムアウトします。画像編集はPNGを対象とし、元画像を上書き、別名で保存して参照を更新、元画像を `archive` に残して同じファイル名で置換、の3方式から選べます。別名保存では保存ファイル名を指定できます。Markdownへ埋め込んだPNGは、ファイル保存ではなくデータURIの参照を差し替えます。画像編集の結果は採用前に確認でき、失敗時は参照変更と画像保存を復旧します。

## 会話履歴

パネル上部の「会話履歴」には保存済みの会話が一覧表示されます。一覧で会話を選ぶと、送信内容、回答、添付画像をプレビューできます。「この会話を開く」を押したときに現在の会話へ戻ります。会話をプレビューしただけでは最終会話日時は変わりません。

保持日数の初期値は30日です。保持日数を短くすると、その時点の期限を過ぎた会話と通信ログを直ちに削除します。0日にすると履歴と下書きを消去し、以後保存しません。設定できる範囲は0〜3650日です。

履歴の会話は最大20往復（送信・回答のメッセージ最大40件）を送信に利用します。送信量は指示、対象本文、履歴本文の合計120,000 UTF-8 bytesまでです。添付画像は最大12枚、送信するbase64データの合計40,000,000 bytesまでで、復号後の1枚あたりの画像データは10MB以下です。

履歴一覧に表示される「キャッシュを利用できない可能性があります」という案内は、最終会話から1時間以上経過した場合に表示されます。1時間を境にキャッシュの有無を断定するものではありません。Codex CLIが返した直近の入力トークン数は、取得できた場合だけ表示します。文字数からトークン数を推定しません。

## 変更案の確認

編集案は大きなプレビューで現在の内容と提案内容を確認できます。図などのプレビューがある場合、初期状態ではコード差分を折りたたみ、プレビューを表示します。「コード差分を表示」から行単位の差分と編集欄を開けます。コード差分を表示した状態では、変更前後のプレビューを左右50:50で表示し、「左右配置」「上下配置」で切り替えられます。

行ごとに「変更前へ戻す」「生成案を再採用」を選べます。変更後を直接編集することもできます。「採用」を押すまで本文や外部ファイルは変更されません。「却下」または閉じる操作で変更案を破棄します。採用後は通常の保存操作でMarkdownへ保存します。

## 右クリックから対象部分について相談する

閲覧側の通常テキスト、コードブロック、Mermaid、draw.io、SVG、画像を右クリックすると、対象に応じたスキルが表示されます。画像の解説・通常文字起こし・表文字起こしは画像の右クリックメニューから選びます。SVG、Mermaid、draw.ioでは既定のOCRを表示せず、解説や図の改善を選びます。画像解説と文字起こしの結果は、可視化後の画像を根拠にします。

閲覧側で文字を選択している場合は、選択した連続範囲をMarkdownソースの行範囲へ対応付けます。対応が一意に決まらない場合は推測しません。選択していない場合は右クリックした段落またはブロック全体を対象にします。パネルには対象本文と位置を表示します。

編集の許可は次の3択です。

| 選択肢 | 送信・適用範囲 |
| --- | --- |
| 質問のみ | 対象部分について回答します。変更案を本文へ適用しません |
| 指定場所のみ編集 | 取り込んだ範囲だけを置換します |
| 指定場所以外の編集を認める | 指定部分を中心に同じ文書の全文を検討・変更します |

## 通信ログ

パネル上部の「ログ」には、成功したCodex CLI通信の送信プロンプトと受信データを表示します。ログには送信した本文、指示、会話履歴が含まれます。ログ画面では送信リクエストと受信応答を確認でき、受信応答はメッセージとオリジナルJSONLを切り替えられます。画像データをログへ保存する機能ではありません。添付画像を含む会話の確認・再開は「会話履歴」を使用します。

ログの保持件数は1〜1,000件で、初期値は20件です。会話保持日数を変更すると、通信ログにも同じ期限が適用されます。共有端末では送信本文が保存されることを考慮し、利用後にアプリのローカルデータを適切に管理してください。CLIが使用量を返した場合だけ、その通信の入力・出力トークンを表示します。

## パネルの幅と範囲

Codexパネル左端をドラッグするか、幅変更のseparatorへフォーカスして左右矢印キーを押すと幅を変更できます。狭い幅でも操作を折り返して表示します。変更案プレビューは左右または上下を選べます。

元文書のファイルパスをCLIへ渡さず、一時作業領域で文章生成を行います。シェル・ブラウザー・プラグイン等を無効化し、元ファイルへの直接編集を許可しません。回答生成のタイムアウトは120秒、PNG画像編集は300秒です。

会話履歴と下書きは、閉じる、文書切り替え、再読み込み、アプリ終了だけで直ちに消えるものではありません。保持日数の期限、0日設定、または利用者の削除操作に従って保存・削除されます。

## 初期版の範囲

ローカルMarkdownの全文／選択範囲、画像、SVG・draw.io・Mermaidの図の相談と書き換え、PNG画像編集が対象です。SharePoint文書、SPFx、複数ファイルの自律編集、公式Codexアプリの会話同期は対象外です。Codex CLI以外のAI実行機能やClaudeの実行機能を再現しません。
