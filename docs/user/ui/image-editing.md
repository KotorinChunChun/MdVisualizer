# PNG・JPEG画像の編集

画像を拡大表示し、「画像編集」を選びます。PNG/JPEGでは次の画面から選択できます。

- **ラスタ編集2**: 矢印、図形、フリーハンド、文字、吹き出し、連番マーカー、モザイク、ぼかし、透かし、切り抜き、サイズ変更などを備えた画像注釈画面。
- **ラスタ編集1**: 従来の注釈、自由描画、塗りつぶし、消去、回転・反転等の編集画面。既存機能は引き続き利用できます。

デスクトップのローカル画像では **ペイント** も選べます。Windowsペイントで保存した変更は画像の再読込みで反映されます。埋め込み画像・Web版・SharePointでは利用できません。

他の画像形式は従来の編集画面を使用します。画像編集の入口がない読み取り専用対象やSPFxへ、新しい入口を追加するものではありません。

## 反映とファイル保存

ラスタ編集1／2の「保存して閉じる」（外部画像）または「文書へ反映」（埋め込み画像）は、注釈を合成した画像をMdVisualizerへ戻します。デスクトップの外部PNG/JPEGは元ファイルへ保存し、既存のバックアップ・復元機能を使用します。JPEGの透明部分は白背景へ合成します。埋め込み画像はMarkdown内の画像をPNGへ置換します。Web版は既存の文書・アセット更新経路を使用します。

画面内の「PNGを書き出す」「JPEGを書き出す」は別ファイルのダウンロードであり、文書への反映とは別です。「編集用保存」の`.spmz`は元画像と注釈を保持する編集用ファイルです。文書へ反映した画像は注釈が焼き込まれるため、後日注釈単位で再編集したい場合は編集用ファイルも保存してください。

「キャンセル」は変更がある場合に破棄を確認して閉じます。外部更新を検出した場合は元画像への上書きを停止し、「最新画像を読み直す」か「編集結果を別名保存」を選べます。読込み直しは現在の編集を破棄する確認を表示します。別名保存はPNGとして新しいファイルへ保存し、編集画面を保持します。保存失敗時は編集画面と編集内容を保持します。

ラスタ編集1で素材画像を選び直した後も、Undo／Redoで前後の素材と注釈を戻せます。ラスタ編集2はSPMZの内容を検証してから読み込み、不正なファイルでは現在の背景・注釈・履歴を保持してエラーを表示します。同じ編集画面で正常なファイルを選び直せます。SPMZの保存形式は変更していません。

## 制約

注釈画面内部は提供HTMLの明るい配色を保持し、外枠はアプリのテーマに従います。隔離した画面で動作するため、描画設定のlocalStorageへの永続保存は使用できません。クリップボード読書きとダウンロードの可否はホストの権限・対応状況に依存します。

## 存在しない画像から作図する

ローカルPNG/JPEGの読込みエラーにある「画像を新規作成」から、幅・高さを指定して白紙を開けます。既定は白背景800×600、各辺1〜4096pxです。ラスタ編集1・2は「保存して閉じる」を押すまでファイルを作りません。ペイントは起動時に白紙ファイルを作ります。保存先に別のファイルが現れた場合は上書きせずエラーになります。破損や読込み権限のエラーは、存在しないファイルとは区別されます。

## 図のコピーと変換

ビジュアル画面で図を右クリックし、「図としてコピー」を選ぶとビットマップとしてコピーします。拡大表示の右上「コピー」には「図としてコピー」「画像ファイルとしてコピー」「コードをMarkdownでコピー」「画像のパスをコピー」「画像のフルパスをコピー」「画像の説明文をコピー」があります。パスはMarkdownの参照文字列、フルパスは通常のWindows絶対パスまたは絶対URLです。埋め込み画像のパスと空の説明文は理由を表示してコピーを無効にします。SVG・Mermaid・draw.ioでは対応するコード・ベクター・ビットマップ・図ファイルのコピーを選べます。ブラウザーではファイルコピーがダウンロードになる場合があります。

コード画面とビジュアル画面では、同じ画像に同じ右クリック項目を表示します。外部画像には「埋め込みに変換」、埋め込み画像には「ファイルへ変換」があります。コピー2項目、変換、AI操作の間に区切りを置いています。文書を更新できない場合は変換を表示しません。ペイントは画像編集の選択画面から起動します。

保存前の画像も、コード・ビジュアルの両画面から図としてコピーできます。参照定義を共有する画像（`![説明][参照名]`）の変換やキャプション変更は、選んだ出現だけを通常の画像記法へ変更し、別の画像と共有定義を保持します。画像記法を説明するインラインコードや通常のリンクには、その隣に画像があっても画像用メニューを表示しません。

保存先のない文書では、変換を選ぶと最初にMarkdownの保存先を選びます。選択を取り消しても入力中の本文は残ります。保存済み文書へ未保存の画像や本文を追加した場合は、その下書きを保持して変換し、通常の「保存」で確定します。コード画面で参照・埋め込みコード内の実ファイルをF2で改名できます。実ファイルがない場合は理由を表示して改名しません。

## キャプション

コード画面へBase64形式の埋め込み画像を貼り付けたり挿入したりすると、画像データ部分は最初から折りたたんで表示します。画像データ自体は省略せず保存します。必要な場合は展開でき、手動で展開した既存画像は新しい画像の挿入で折りたたみ直しません。

AI提案からの挿入にも同じ折りたたみを適用します。画像の削除・置換をUndo／Redoした場合は本文とともに折りたたみを復元し、画像データの更新でも元の展開状態を維持します。

コード画面の画像挿入は、選択文字がなければ空のキャプションで挿入します。ビジュアル画面のキャプションをダブルクリックすると編集できます。空欄には「キャプションを追加」を表示しますが、この案内自体は文書に保存されません。Enter／F2でも編集を開始でき、入力後はEnterで確定、Escapeで取消します。

「AIでキャプション生成」は、選んだ画像の説明文だけを変更候補にします。同じ画像を複数箇所で使っていても選択箇所だけが対象です。コードとビジュアルの差分を確認し、「決定」で反映します。詳しい手順は[AI利用ガイド](/docs/user/ui/codex.md)を参照してください。

キャプションの記号は、手動編集とAI生成のどちらでも説明文の文字として保持します。表の区切りや強調などの記法として解釈されないよう保存時に保護します。Wiki形式で説明文を安全に表せない場合は、参照先と説明文を保って通常の画像記法へ変換します。

説明文の変更後、表示履歴の「戻る」で拡大画面を開いても現在の説明文をコピーします。画像の位置や参照先が変わり同じ画像と確認できない場合は、古い対象で操作せず、現在の画像から開き直す案内を表示します。

## 読込みや起動に失敗した場合

選択画面の「再試行」で元画像を読み直すか、「画像を選び直す」で編集に使う画像を指定できます。選び直した時点では元ファイルを変更しません。新規白紙作成後にペイント起動だけ失敗した場合は、再操作で作成済みの画像を開き、重複作成を避けます。
