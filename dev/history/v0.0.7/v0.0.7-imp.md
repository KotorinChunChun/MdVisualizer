# 爆速 Markdown Viewer v0.0.7 実装計画書

対応要求: [`v0.0.7-req.md`](./v0.0.7-req.md)
作成日: 2026-08-09 / ステータス: **実装・自動検証完了（GUI受入未実施）**
作業ブランチ: `feature/v0.0.7`

## 1. 共通方針

- 4フェーズに分け、各フェーズで対象テスト、全frontend test、production buildを実行してからコミットする。
- 設定値は型付きの正規化helperを通し、未知値や壊れた保存値で起動を妨げない。
- Markdown由来のコードは自動実行せず、ユーザー操作と実行直前の確認を必須にする。
- HTML文字列の挿入を増やさず、検索・ログ・設定値はReactのテキストとして描画する。
- GUI自動操作はリポジトリ規則の5秒入力監視を通過した場合だけ開始する。

## 2. Phase 1: 単一サイドパネル

- 目次、検索、画像を同じパネルの3タブとして排他的に表示する。
- 検索入力、条件、前後移動、件数、結果一覧を検索タブ内へ移す。
- 画像タブは既存のサムネイル、alt相当のcaption、使用箇所ジャンプを再利用する。
- 860px以上は本文幅を確保するsidecar、859px以下はbackdrop付きdrawerにする。
- `Ctrl+F`は検索タブを開き、開いている場合も入力欄へfocusして全選択する。
- 文書／タブ切替時に別文書のパネル状態や選択位置を誤表示しない。

## 3. Phase 2: シンタックスハイライト設定

- Settingsでhighlight.js配色プリセットと基本色を選べるようにする。
- light／darkテーマ双方に決定的な既定値を持たせる。
- 設定変更後もコード検索のmarkとhighlight.jsのtoken DOMを維持する。
- 保存値を正規化し、再起動後に復元する。

## 4. Phase 3: PowerShellコード実行

- `powershell`、`pwsh`、`ps1`と明示されたコードブロックだけに実行ボタンを表示する。
- 自動実行を禁止し、実行ごとにコード要約・作業ディレクトリを示す確認を行う。
- Markdown文書のディレクトリを作業ディレクトリとし、非対話・時間制限付きで`pwsh`を起動する。
- stdout／stderr／終了コード／timeoutをコードブロック単位の出力欄へ表示する。
- 多重実行、文書切替後の古い結果反映、HTML再解釈を防止する。

## 5. Phase 4: 印刷スタイル設定

- 見出し色、罫線色、背景色、本文フォント、白黒モードをSettingsへ追加する。
- 値をCSS custom propertiesへ限定して反映し、任意CSS文字列は受け取らない。
- 白黒モードは印刷時だけに適用し、画面テーマを変更しない。
- 通常印刷とプレゼン印刷の双方で設定を共有する。
- 不正保存値は安全な既定値へ戻す。
