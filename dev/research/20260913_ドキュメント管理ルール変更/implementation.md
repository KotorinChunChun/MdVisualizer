# 版別資料配置への移行

対象: MdVisualizerの資料・生成スクリプト・録画スキル。版に属さない開発運用の整理記録。

## 確定方針

- 過去・進行中・未来の版別記録は、最初からdev/history/vX.Y.Z/へ置く。
- 版に属さない調査・検討はdev/research/へ置く。researchにログ用フォルダーは設けない。
- テスト動画・生ログ・台帳・生成結果は対象版のlogsへまとめ、Git対象外とする。
- dev直下のファイルは継続的なルールと目録だけとする。
- docsは現行仕様・操作・再現可能な手順を扱う。

## フェーズ

- [x] グローバルAGENTS、関連5スキル、共通PROJECT_RULEとgitignore見本の方針を修正。
- [x] 本プロジェクトの資料移動、リンク修正、配置ルール・目録更新、差分検証。生成元と同じ変更単位でコミットする。
- [x] 録画とテスト出力の生成元修正、版別ログへの既存証跡移動、対象検証。資料移動と同じ変更単位でコミットする。
- [x] [他プロジェクト向け依頼プロンプト](other-project-prompt.md)を作成。

## 保存する内容

要求原文、判断、未確認事項、提供原本、動画・生ログを削除しない。旧計画と現行仕様が混在する資料は原文を当時の版へ保管し、docsには現行の入口を残す。

ユーザーによるdev/PLAN_IDEAS.lockの削除は本作業へ取り込まない。その他の移動はリンクとコード内参照を同時に更新する。試作の受入を本体の合格へ読み替えない。

グローバルの方針変更はプロジェクトのGit管理外。skill標準検証器はPythonのPyYAML不足で起動できなかったため、既存Node.jsのyamlパーサーで5スキルのfrontmatter、命名、説明、未完成記述、既存メタデータの不変を確認した。

初回の[整理案](2026-09-13-initial-plan.md)は採用前の記録。配置は本書の確定方針を優先する。

## 移動・参照の確認

- 版別文書、設計提案、版付きアイコン制作資料など333ファイルを移動。旧版の完了判定による足止めをやめ、v0.0.18も同じhistory内へ配置した。
- dev直下はREADME.md、RELEASE_RULE.md、Microsoft Store公開方針.mdのみ。
- 動画・ログ・生成結果151ファイルは移動前後のSHA-256一致を確認。その後14件の録画台帳のvideo/log/progressを新位置へ更新した。
- 0.0.17.1 betaは従来どおりv0.0.17フォルダー内に含める。Mermaid試作の既存証跡は実装記録の実行ブランチv0.0.17-betaに対応するv0.0.17/logsへ保存し、本体の合格証跡とは区別した。
- 図の提供原本と回帰用samplesは内容が異なるため両方保持。履歴の旧製品名、要求の意味、保留状態は変更していない。
- 資料リンク検査では新規の参照切れ0件。元からある記法例・クエリー付きリンクは実ファイル欠落と区別して扱う。

## 生成処理の検証

- JavaScriptの版別保存先: 版未指定、パストラバーサル、版・実行の分離、別版やdev直下への逸脱拒否の4件成功。
- PowerShellの保存先・不正版拒否、変更したPowerShell4ファイルとJavaScriptの構文検査成功。
- 起動スクリプトの命名・構文・WhatIf確認成功。npm.cmdがPATHにないため同じ入口のPowerShellを直接実行した。
- 録画スクリプト: 必須版、重複抑止、版の分離、別版の稼働中検出、移行台帳のstatus/stop/review、開始時の出力先について6件成功。隔離した架空台帳と起動モックによる確認であり、実録画は行っていない。
- 編集HTML生成の最初の試行はViteのSSR通信が60秒でタイムアウト。通常環境で同じ処理を再実行し、v0.0.18/logs/2026-09-13T13-45-55-265Z-editing-afc65157/に3992件の結果HTMLを生成できた。dev直下への再生成はない。結果HTMLと移行した録画台帳がGit除外対象であることを確認した。

本体ソース・版番号・配布物は変更していない。実アプリGUI・実録画・リリース・公開は実施していない。録画の保存経路は回帰テストで確認しており、実録画の品質を検証したという報告ではない。
