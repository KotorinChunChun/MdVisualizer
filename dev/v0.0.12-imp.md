# v0.0.12 実装計画・報告

## 状態

- 2026-08-27: ユーザー確認により仕様を確定した。
- 2026-08-27: `feature/v0.0.12`ブランチで実装を開始した。

## 既存実装の再利用方針

- CSV／TSVの`DelimitedTableBlock`にあるGUI表編集を標準Markdownテーブルへ共通化する。
- `MermaidToolbar`のコード、PNG、SVGコピーを図表共通操作へ整理し、draw.io全画面でも利用する。
- draw.ioの安全なMarkdown出現位置置換、一時資産ステージ、埋め込み／外部切替をMermaidへ一般化する。
- Mermaidの描画キュー、世代管理、状態APIを維持し、エラー描画だけを隔離する。
- 各フェーズ終了時に対象テスト、全テスト、型検査、production buildを行い、日本語メッセージで対象差分だけをコミットする。
- GUI実画面確認は5秒入力監視付き`pwsh -NoProfile -File .\scripts\run-debug-MarkdownViewer-all-smoke.ps1`を使用する。

## 実装フェーズ

### フェーズ1: 版更新、コード枠、ショートカットSVG

- 全マニフェストを0.0.12へ更新する。
- リッチコードフェンスの外側`pre`だけを明示的に無装飾化する。
- 共有ショートカット解析を、先頭修飾キー、記号キー、日本語操作名へ拡張する。

#### 実装結果

- ルート、共有コア、Tauri、SPFxの版を0.0.12へ更新した。
- リッチコードフェンス直下の専用レンダラーに限り、React Markdownが生成する外側`pre`の背景、余白、境界線を無効化した。
- ショートカット認識を「最初のキーが修飾キー」の条件へ厳密化しつつ、記号、矢印、日本語操作名、`Windows++`を扱えるようにした。
- 共有コアのビルド、対象テスト3ファイル33件、フロントエンド全104ファイル4565件、TypeScript型検査、Vite production build（2572モジュール）に成功した。
- SPFx production buildとJest 4スイート11件、`.sppkg`生成に成功した。公開やアップロードは実施していない。

### フェーズ2: 標準MarkdownテーブルGUI編集

- 位置、配置、改行コードを持つGFMテーブル出現モデルと安全な置換処理を追加する。
- CSV／TSVの表編集ダイアログを共通コンポーネントへ分離し、配置選択を追加する。
- Markdownプレビューのテーブル右上へ鉛筆ボタンを配置し、ドラフト更新へ接続する。

#### 実装結果

- GFMテーブルを正確な文字範囲、元文字列、配置、改行コード、引用継続接頭辞とともに収集し、競合時には誤置換しない安全更新を実装した。
- CSV／TSVの編集UIを`TableEditorDialog`へ共通化し、標準Markdown表では列ごとの既定／左／中央／右配置を変更できるようにした。
- 標準Markdown表の右上へ鉛筆ボタンを配置し、ローカルMarkdownの通常プレビューだけで編集可能にした。読み取り専用、静的、プレゼンテーション表示ではボタンを出さない。
- セル内の未エスケープ`|`を自動エスケープし、複数行入力は`<br>`へ正規化する。CRLFと引用内テーブルの接頭辞も保持する。
- 対象テスト4ファイル17件、追加境界テストを含む最終対象2ファイル12件、全105ファイル4570件、TypeScript型検査、Vite production build（2573モジュール）に成功した。

### フェーズ3: 図表共通ヘッダー、全画面コピー、Mermaidエラーと仮編集

- 図表共通ツールバーとカード見出しを作成し、Mermaidとdraw.ioへ適用する。
- 全画面プレビューへ図種と元ソースを渡し、draw.ioでも3種類のコピーを表示する。
- 全画面Mermaidから表示切替だけを除去する。
- MermaidのエラーSVG生成を抑止し、詳細ポップアップと仮GUI編集モーダルを追加する。

#### 実装結果

- Mermaidをdraw.ioと同じ見出し付きカードへ変更し、コード／PNG／SVGコピーと本文内のプレビュー／コード切替をヘッダーへ集約した。
- 図種と元ソースを全画面プレビューへ渡し、Mermaidとdraw.ioの双方でコード、ラスタ画像、ベクタ画像をコピーできるようにした。全画面内のプレビュー／コード切替は削除した。
- `suppressErrorRendering`を有効にし、Mermaidのエラー本文をコンパクトな通知と固定サイズの詳細ダイアログへ隔離した。
- Mermaid見出し左側の鉛筆ボタンから、現在のコードを確認できるGUI編集準備中モーダルを起動できるようにした。
- 対象テスト6ファイル55件、全105ファイル4573件、TypeScript型検査、Vite production build（2574モジュール）に成功した。

### フェーズ4: Mermaid保存形式切替、外部draw.io、空キャンバス

- Mermaid用の外部参照、コードフェンス、推奨ファイル名、ステージ処理を実装する。
- `.mmd`／`.mermaid`を本文内表示する外部Mermaidブロックを追加する。
- 外部draw.ioの保存済み／一時ステージ編集経路を統一する。
- draw.io XMLの描画セル有無を判定し、空図のプレビュー高を約100pxにする。
- draw.io公式JSONプロトコルのload時fitとload完了後fitを使用し、Page ViewをURLとXMLの双方で無効化して既存図形を編集領域中央へ表示する。
- Mermaid編集ボタンをdraw.ioと同じ「見出し名の直後」へ揃える。
- 共通表編集ダイアログを単一行セルのグリッドへ変更し、キーボード移動、矩形選択、TSVコピー／貼り付け、貼り付け時の行列自動拡張を追加する。

#### 過去仕様の調査結果

- `dev/history/v0.0.9/v0.0.9-req.md`には「表編集画面から行、列、セルを編集」とあり、`dev/history/v0.0.9/v0.0.9-imp.md`にもヘッダー／セル変更と行列追加削除の実装記録がある。
- `dev/drawio_markdown_sample.md`にはCSV／TSVの「WYSIWYG編集」と、セル値／カラム名変更、任意の行列削除が明記されている。
- 一方、表計算ソフトのような単一行グリッド、矩形選択、キーボード移動、複数セルコピー／貼り付けは過去文書に明記されていなかったため、本版の要求と受入基準へ追加した。

#### 実装結果

- Mermaidコードフェンスを同一フォルダーの`.mmd`へ一時ステージし、Markdown保存時に確定する経路と、`.mmd`／`.mermaid`画像参照をコードフェンスへ戻す経路を追加した。保存済み外部ファイルは自動削除しない。
- 標準Markdown画像記法と明示的なObsidian埋め込み記法で外部Mermaidを本文描画し、外部ファイル変更監視にも追加した。
- 保存済み外部draw.ioは競合検査付きで直接保存し、一時ステージ中のdraw.ioはステージ内容を更新できるようにした。
- draw.ioビューアー取得後はレスポンシブSVGへ置換し、空XMLまたは空ソースは初期表示と取得後表示の双方を100pxに固定した。
- draw.io編集iframeでPage Viewを無効化し、load時とload完了後に最大100%のfitを行うようにした。Page View切替との競合で図が左上へ戻る経路を除去した。
- Mermaid編集ボタンを見出し名の直後へ移し、draw.ioと同じ「編集」ラベルへ統一した。
- 共通表編集を単一行セルのグリッドへ変更し、矢印／Enter／Tab移動、Shift／ドラッグ矩形選択、TSV範囲コピー、複数セル貼り付け、範囲消去、不足行列の自動追加を実装した。
- 対象テスト12ファイル68件、フロントエンド全109ファイル4584件、Rust全107件、TypeScript型検査、Vite production build（2576モジュール）に成功した。

### フェーズ5: 統合検証と記録

- 対象テスト、共有コア、全フロントエンド、Rust、SPFxを検証する。
- TypeScript型検査、デスクトップ版とSPFx版production buildを実行する。
- 規定の実画面スモークを実行し、受入基準と結果を本書と進捗管理へ記録する。

#### 統合検証結果

- フロントエンド全109ファイル4584件、Rust全107件が成功した。
- 共有Markdownコアを含むデスクトップproduction build、TypeScript型検査、Vite production build（2576モジュール）が成功した。
- SPFx production build、Jest 4スイート11件、`spfx-markdown-editor.sppkg`生成が成功した。公開、アップロード、展開は行っていない。
- 規定の`pwsh -NoProfile -File .\scripts\run-debug-MarkdownViewer-all-smoke.ps1`を実行したが、起動中のMarkdownViewer（PID 3252）がデバッグ状態APIへ応答しなかった。スクリプトは未保存タブ保護のため対象プロセスを強制終了せず、安全に中止した。
- このためDOM実解析と実画面キャプチャだけは未実施である。利用者が当該MarkdownViewerを閉じた後、同じ規定スクリプトを再実行する必要がある。

#### 受入基準の確認

- 表グリッドの移動、矩形選択、TSVコピー／貼り付け、行列自動拡張はコンポーネントテストで確認した。
- draw.ioの空表示100px、外部保存済み／一時ステージ編集、編集iframeのfitメッセージは単体・コンポーネントテストで確認した。
- Mermaidの共通ヘッダー、編集ボタン位置、エラー隔離、全画面コピー、仮GUI編集、`.mmd`相互変換と外部描画は単体・コンポーネントテストで確認した。
- ショートカットSVG、コード外枠、デスクトップ／SPFx共有コアは全テストと双方のproduction buildで確認した。
- draw.io編集画面での目視上の中央配置を含む実画面受入確認は、上記の安全中止により保留している。
