実施日: 2026-08-10
対応要求: [`v0.0.7-release-automation-req.md`](v0.0.7-release-automation-req.md)

## 1. 結果

MSIX／App Installerのstable・betaリリースを安全に反復するため、プロジェクト設定、共通PowerShell module、
明示確認付きオーケストレーター、個人skill `publish-msix-release`を実装した。

既定動作は読み取り専用の`Plan`であり、ユーザーが明示的に望まない限り、テスト、release build、
MSIX／App Installer生成、サイト配置、FTP公開、アプリインストールを開始しない。

## 2. プロジェクト側

追加・汎用化した主なファイル:

- `packaging/release-config.json`
- `scripts/ReleaseTools.psm1`
- `scripts/build-msix.ps1`
- `scripts/build-appinstaller.ps1`
- `scripts/stage-msix-release.ps1`
- `scripts/verify-msix-release.ps1`
- `scripts/verify-published-msix-release.ps1`
- `scripts/publish-msix-release.ps1`
- `scripts/test-release-automation.ps1`

設定からapplication version、4要素MSIX version、Identity、Publisher、architecture、成果物名、Web配置先、
stable／betaのApp Installer URIとMSIX URIを導出する。既存の`stage-beta-release.ps1`と
`verify-beta-release.ps1`はbeta互換wrapperとして残した。

MSIX buildもrelease configからPublisher、Identity、artifact名、architecture、証明書Friendly Nameを
取得するため、App Installer／stage／verifyと同じ設定を単一の情報源として使用する。

## 3. モードと安全境界

| Mode | 動作 | 必須switch |
| :--- | :--- | :--- |
| Plan | 予定version／Identity／URL表示のみ | なし |
| Build | test、release build、MSIX署名、App Installer生成 | `-ReleaseIntentConfirmed` |
| Stage | 既存成果物のWebツリー配置とローカル検証 | `-ReleaseIntentConfirmed` |
| Publish | FTP dry-run、FTP公開、公開検証 | `-ReleaseIntentConfirmed -PublishConfirmed` |
| Verify | 既存local／published成果物の読み取り検証 | なし |
| Full | Build、Stage、Publish、Verify | `-ReleaseIntentConfirmed -PublishConfirmed` |

Build／Stage／Publish／Fullは確認switchの検査を外部コマンドより前に行う。Publish／Fullは公開専用switchも
要求するため、リリース成果物生成の依頼をFTP公開許可へ拡張しない。

## 6. 意図的に実行しなかった事項

今回の依頼は自動化skillの実装であり、新しいリリースやインストーラ生成の依頼ではないため、次を実行していない。

- frontend全test
- Rust全test
- production／Tauri release build
- MSIX／App Installer生成
- 証明書作成・変更
- WebツリーへのStage
- FTP接続・アップロード
- アプリのインストール／アンインストール
- GUI操作

製品コードは変更していない。構文、設定、安全guard、既存成果物の読み取り検証を完了条件とした。

## 7. 利用例

計画だけ:

```powershell
pwsh -NoProfile -File .\scripts\publish-msix-release.ps1 -Mode Plan
```

ユーザーが明示的にbetaインストーラ生成を依頼した場合:

```powershell
pwsh -NoProfile -File .\scripts\publish-msix-release.ps1 `
  -Mode Build -Channel beta -ReleaseIntentConfirmed
```

ユーザーがend-to-endのbeta公開を明示的に依頼した場合だけ:

```powershell
pwsh -NoProfile -File .\scripts\publish-msix-release.ps1 `
  -Mode Full -Channel beta `
  -ReleaseIntentConfirmed -PublishConfirmed `
  -PythonPath <python-executable>
```
