## 確定した出力仕様

| 項目 | スクリプトなし (`static`) | スクリプトあり (`interactive`) |
|---|---|---|
| 本文、全行・全列の表、図・画像 | 単一HTML内に格納 | 同左 |
| コード左上の言語名・ファイル名 | コード枠内に小さく表示 | 同左 |
| JavaScript | 一切含めない | nonceで許可した内蔵操作スクリプトのみ |
| コード・表のコピー | なし | 右上のボタン。結果通知は約3秒で消去 |
| コード・表の折り返し切替 | なし | 本文の表示幅に合わせて切替 |
| 目次 | なし | 画面右上固定。見出しリンクと全展開／全折りたたみ |
| 見出しの折りたたみ | なし | H2〜H6。H1は維持。リンク移動時に対象章を展開 |
| 図・画像の拡大 | なし | クリック／Enter／Spaceで開く。拡大・縮小・Escで閉じる |
| 表の並べ替え | なし | 列ごとに昇順→降順→元の順。数値同士は数値比較 |
| 表の絞り込み | なし | 全列の部分一致。大文字・小文字を区別しない |

既定はstatic。編集、AI、プレビュー切替、アプリの右クリックメニュー、Markdown／Mermaid編集連携は、どちらにも出力しない。閲覧時のReact、Mermaid、draw.io等の描画エンジンや外部CDNは不要。interactiveもJavaScript無効時は本文を閲覧でき、使用できない操作ボタンは表示しない。

表のコピーは現在の表示行と並び順に従うTSVで、見出しと集計行を含む。合計・平均・個数の集計行は検索中も表示し、並べ替え時は末尾に残す。集計値は全行に対する値を維持し、「集計は全行」と表示する。検索後の再集計は行わない。印刷時は操作UIを隠し、折りたたみ・検索で隠した内容も表示する。

本文・表・コードはHTML。Mermaidは出力専用設定でHTMLラベルを無効にしてSVG化する。PlantUMLは既存のローカル対応範囲でMermaidへ変換する。SVGにforeignObjectが残る図は図単位のPNGへ変換する。draw.ioは全ページを対象とする。画像は元形式を基本にData URLで埋め込む。文章全体の画像化はしない。

## 本体の操作契約

2026-09-14の最終訂正により、対象はWindowsデスクトップ版とSPFx版。デスクトップで開いたSharePoint文書も対象に含めるが、その認証連携は未実装である。SPFxは既存の保存・認証仕様を維持し、HTML出力ボタンからスクリプトあり／なしを選択してブラウザーでダウンロードする。ファイル名を指定できるようにし、保存先フォルダーはブラウザーの保存操作に従う。以下のネイティブ保存・原子的ファイル反映はデスクトップ向けであり、SPFxでは完成したHTMLをダウンロードする経路に置き換える。

1. 「印刷/PDF」のすぐ右に「HTML出力」を配置する。
2. 保存先とファイル名を指定する際に「スクリプトなし」「スクリプトあり」の2択を提示する。内部値はstatic／interactiveを使用する。ネイティブ保存ダイアログに選択欄を追加できない場合の具体的なUI構成は統合時に確定する。
3. 出力開始時点のアクティブ文書、未保存の本文、表示テーマ、本文CSS、資産の参照元を固定する。ファイルの再読込で未保存本文を置き換えない。
4. 折りたたみ・絞り込み・ページ送り・列非表示の状態を持ち込まず、全文・全行・全列・図表示で生成する。スクロール位置により未描画の範囲を欠落させない。
5. 二重実行を防ぎ、進捗と中止を提供する。処理中の編集・タブ切替が出力対象をすり替えないよう、文書IDと世代を保持する。
6. 完成したHTMLを一時ファイルへ書き終えてから保存先へ反映する。キャンセル・取得失敗・描画失敗・容量超過で既存HTMLや元文書を破損しない。
7. 完了／失敗を通知する。欠落した図をコードやプレースホルダーに置き換えて成功扱いにしない。

## 現行コードの責務とAPI

| ファイル | 現在の責務 |
|---|---|
| `scripts/export-html.mjs` | CLI引数、入力文字コード、標準入力、終了コード |
| `scripts/html-export/export.mjs` | Node側のexportHtml、Viteバンドル、Playwright起動、進捗、中止、PNG取得、保存 |
| `scripts/html-export/browser.tsx` | 出力専用描画、資産埋込、SVG処理、CSS固定、サニタイズ、HTML生成 |
| `scripts/html-export/controls.ts` | 出力UIのCSS・マークアップ、コード情報、目次 |
| `scripts/html-export/runtime.ts` | interactive内蔵操作スクリプト |
| `scripts/html-export/io.mjs` | 資産取得、容量・参照制限、安全な保存 |
| `tests/html-export/` | IO、独立HTML受入、実draw.io受入 |
| `samples/html-export.md` | 図・表・コード・両モードの共通入力例 |

exportHtmlはNode.js向けの非同期関数で、Tauriフロントエンドから直接importして実行できるAPIではない。

| 引数 | 契約 |
|---|---|
| markdown | 必須。出力する本文文字列 |
| output | 必須。保存先HTMLパス |
| baseDir | 資産の相対参照元。既定はNodeの作業ディレクトリー |
| title / theme / css | HTMLタイトル、固定するテーマ、追加CSS |
| mode | static／interactive。既定static |
| force | 既存HTMLの上書き許可 |
| allowRemote / drawioViewer | HTTP取得許可／信頼するローカルdraw.ioビューアー |
| browserPath | 生成用Chromium実行ファイルの指定 |
| signal / onProgress | AbortSignal／進捗文字列のコールバック |
| protectedPaths | 上書き禁止の入力等を渡すSet。資産取得で読んだパスも保護する |

返却値はoutput、mode、bytes、items、diagrams、tables、rasterized。失敗時は例外。diagramsは現在の実装では直接指定した図タスクの件数で、外部参照の図やdraw.ioのページ数を完全に数える総数ではない。本体の進捗分母として無条件に流用しない。

## 統合時に実装する橋渡し

現行CLIは実行時にNode.js・Vite・Playwright・Chromiumを使用する。ユーザー環境へそれらが存在する前提で単にCLIを起動しても、配布済み本体への統合完了とはならない。

本体の実行環境を選定したうえで、以下を接続する。推奨は、生成側のブラウザーコードをビルド時に用意し、本体から隔離した出力ホストと既存のTauri資産取得・保存経路を利用する方式。これは統合方針であり、実装済みではない。

- 文書スナップショット: 未保存内容、テーマ、CSS、参照元、世代を取得する。
- 出力ホスト: 通常プレビューとDOM・Mermaidの状態を分離し、準備完了・エラー・中止を受け取る。
- 資産取得: `__readAsset(source, base)`相当の契約（base、mime、必要に応じtext、data）を本体の許可済みファイル／一時資産／SharePoint認証経路で実現する。トークンや認証情報をHTMLへ格納しない。
- 図生成: `__drawioViewer`相当の供給経路と配布資産を決める。HTMLラベルを含む図のPNG化は、現在のPlaywright要素スクリーンショットに相当する手段を検証する。WebViewへの移植だけで同品質が得られると仮定しない。
- シリアライズ: prepare→PNGが必要な図の置換→finish(mode, nonce)の順序を維持する。元文書のスクリプトとイベントを除去し、interactiveだけ生成側の操作スクリプトを許可する。
- 保存: ファイル選択、上書き確認、入力保護、原子的な保存、後始末を本体側へ接続する。

上限の現行値はMarkdown 8 MiB、資産単体32 MiB、資産合計と完成HTML各128 MiB、処理120秒、HTTP転送5回。PNG化は最大辺8192 CSS px、2倍解像度で1600万画素まで。移植時も判定を失わない。

## 引き継ぐ検証と本体導入の完了条件

CLIの直近検証は15件成功、型検査成功。実draw.ioの非圧縮／圧縮・複数ページの検証は先行段階で成功しており、直近15件とは別実行である。Edgeでオフライン、元資産削除後の閲覧、両モード、コピー、3秒通知、図拡大、章開閉、表操作、明暗、390px幅、印刷表示を確認した。Firefox・Safari・iPhone／Android実機は未確認。

本体導入時にはCLIの回帰に加えて、次を確認する。

- [ ] 「印刷/PDF」右のボタン、保存時の2モード選択、キャンセル、既定static。
- [ ] 未保存文書、タブ切替、処理中の更新・連続実行でも固定した文書を出力。
- [ ] ローカル・一時資産・SharePoint認証資産、長文・未描画範囲・全行全列。
- [ ] SVG／PNG・日本語・図内画像・全draw.ioページの欠落なし。
- [ ] 元文書・既存HTML保護、容量上限、失敗／中止時の後始末、資格情報非混入。
- [ ] staticのscript不在とinteractiveの許可済み操作のみ。オフラインでHTML単体閲覧。
- [ ] 本体の印刷/PDF、プレビュー、編集、保存への回帰がない。
- [ ] 配布環境に開発用Nodeやnode_modulesがなくても生成できることを確認。
- [ ] 当該PCのAGENTS.mdに従ってデバッグ本体の実操作を確認し、未確認環境を記録。

本体への導入・デバッグ検証と、署名・インストール・外部公開は別作業として管理する。採用版の要求・計画へ取り込む際も、CLI完成と本体導入完了を区別する。
