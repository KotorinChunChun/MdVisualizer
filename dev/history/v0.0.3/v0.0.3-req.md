# 爆速 Markdown Viewer v0.0.3 要求定義書

作成日: 2026-07-29  
レビュー確定日: 2026-07-30  
ステータス: **実装・検証完了**

## 1. 目的

v0.0.2の高速閲覧を維持しつつ、閲覧位置の意味的な復元、利用者定義の外部アプリ、
見出し階層を使い動画・スライドショーへそのまま利用できるプレゼン閲覧を追加する。
あわせて、全テーマで表見出しとインラインコードが判読できる配色を保証する。

## 2. 要求仕様

### 2.1 テーマ配色の回帰修正

* ライト／GitHubを含む全テーマで、表見出しとインラインコードの背景色・文字色をテーマ別に定義する
* CSS変数の宣言値だけでなく、WebView上の計算済みスタイルとスクリーンショットで判読性を確認する
* 表見出しは本文と区別でき、文字との十分な明度差を持つ
* インラインコードは本文から識別できるが、文字を隠すほど濃くしない

### 2.2 意味的スクロールアンカー

Markdown保存・自動再読込の前に、現在画面上部で見えている本文位置を文書内アンカーとして記録する。
再描画と折りたたみ状態復元後、同じ内容へスクロールする。

アンカー候補:

* 最寄りの見出しfold-idと見出し階層
* 可視ブロックのテキスト指紋
* ブロック内の表示オフセット
* 文書全体に対するスクロール比率（最終フォールバック）

対象テキストが削除された場合は、同じ見出し、直前ブロック、スクロール比率の順で安全にフォールバックする。
一致候補が複数ある場合の選択方式は実装者へ委任するが、予測可能でテスト可能な優先順位を持たせる。

### 2.3 設定専用タブ

* ステータスバー右端に歯車ボタンを置く
* 歯車ボタンで設定専用タブを開く
* 設定タブは1つだけ存在し、複数回押した場合は既存タブをアクティブにする
* 設定タブから通常のMarkdownタブへ戻れる
* 設定の保存失敗は既存のトーストで通知し、入力内容を失わない

### 2.4 外部アプリ

* 外部アプリを追加、編集、削除、並び替え、有効／無効にできる
* 表示名、実行ファイル、引数配列、作業フォルダー、表示場所を設定できる
* 実行ファイルと引数配列は分離し、`${file}`／`${dir}`／`${line}`だけを置換する
* シェル文字列、パイプ、リダイレクト、任意の環境変数展開は評価しない
* 初期状態では「フォルダー」「VS Code」を上部の直接ボタンにする
* 「その他」サブメニューを設け、初期アイテムとして「メモ帳」を登録する
* 設定画面で任意の外部アプリを直接ボタンまたは「その他」サブメニューへ振り分けられる
* フォルダー操作も表示場所を設定できる既定アクションとして扱うが、削除不能とする

### 2.5 階層型プレゼンモード

見出しを階層化したページとして表示し、ほぼスクロールせずに動画・スライドショーへ利用できるようにする。

#### 2.5.1 ページとナビゲーション

* 左右矢印キーと画面ボタンで前後ページへ移動する
* 上部に `見出し1 (1/1) > 見出し2 (2/4) > 見出し3 (1/5)` 形式のパンくずを表示する
* パンくずの階層数は制限せず、1行横スクロールで現在階層が見える位置へ自動追従する
* パンくずの各要素はクリックで移動できる
* 見出しのない文書、飛び級見出し、同名見出しでも安定したページIDを生成する
* 通常表示へ戻る際は対応する見出し位置へ復帰する

#### 2.5.2 子見出しのページ分割

* 直下の子見出しが複数ある場合、親ページには小見出しリストだけを表示する
* 直下の子見出しが1つだけの場合、その子見出し本文が設定値以下なら親ページへ含める
* 暫定設定値はMarkdownソース上の論理行数10行とする
* 子見出しが1つでも設定値を超える場合、親ページには小見出しリストを表示し、本文は別ページにする
* 小見出しリストの項目はクリックで対象ページへ移動できる

#### 2.5.3 表示領域

* 画像は見出し・パンくず・ページ操作を除いた画面内へ収まるよう自動縮小する
* 短い本文は原則としてページ内スクロールを発生させない
* 文章量、表、コード等が画面に収まらない場合はページ内スクロールを許可する
* Mermaid、画像、表、コードはページ内で通常どおり表示する

#### 2.5.4 画像拡大と編集遷移

* プレゼン内の画像を1回クリックすると、ウィンドウ内全画面のポップアップで表示する
* `Esc` でポップアップを閉じる
* ポップアップ上のホイール操作で画像を追加拡大・縮小できる
* 拡大の中心はポインター位置を基本とし、最小は全体表示、最大倍率は安全な上限を設ける
* ポップアップ画像をもう一度クリックすると編集モードへ移る
* 編集へ移れるのはローカルのラスター画像だけで、既存クロップ編集を利用する
* SVG、外部画像、data画像は拡大閲覧までとし、編集へは移らない

## 3. 対象外

* SVGのベクタ編集
* Markdown本文の編集
* PowerPoint/PDFへの書き出し
* 任意シェルコマンドの実行

SVGベクタ編集は別バージョンで要求を相談してから計画する。

## 4. 受入基準

### 4.1 テーマ

* 全テーマについて、表見出し・本文・インラインコードの計算済み背景色がテーマ定義どおり異なる
* ライト／GitHubで暗い背景に暗い文字という組み合わせが発生しない
* テーマを連続切替しても前テーマの背景色が残らない

### 4.2 スクロール復元

* 表示位置より前へ行を追加・削除して保存しても、同じテキストブロックが画面内へ戻る
* 折りたたみ状態を復元してからアンカー位置を確定する
* アンカーが消えても例外にならず、予測可能なフォールバック位置へ移動する

### 4.3 外部アプリと設定

* GUIからアプリを登録し、再起動後も保持する
* 直接ボタンとサブメニューの振り分けが設定どおり反映される
* ファイルパスに空白、日本語、`&`、`%`、引用符が含まれても単一引数として安全に渡す
* 実行ファイルが消えた場合は設定を破壊せずエラー表示する
* 複数プロセスから設定を更新しても別項目を失わない

### 4.4 プレゼン

* キーボード、ボタン、パンくず、小見出し一覧から同じページ状態へ遷移する
* 兄弟位置と総数が階層ごとに正しく表示される
* 子見出し0件、1件（10行以下／超過）、複数件でページ分割規則が守られる
* 通常表示へ戻った際に対応する見出し位置へ復帰する
* 長いページだけがページ内スクロールでき、左右キーとの競合を起こさない
* 画像が初期表示で画面内に収まり、ポップアップ、ホイール拡大、Esc、ラスター編集遷移が動作する

## 6. 実装済

2026-07-30、2.1〜2.5を全件実装済みへ移動した。

* テーマ別の表見出し・インラインコード・リンク配色と、release WebView上の計算済み色／コントラスト検証
* fold、テキスト指紋、ソース行、比率を使う意味的スクロール復元
* 歯車から開く単一設定タブ、プレゼン統合行数設定
* ID単位で競合をマージする外部アプリCRUD、直接ボタン／その他メニュー、安全な引数展開
* 10ソース行規則、無制限パンくず、子一覧、通常表示復帰を備える階層プレゼン
* 画像fit、全画面ポップアップ、ホイール拡縮、Esc、ローカルラスター編集遷移

検証結果とSol監査後の追加修正は [`v0.0.3-report.md`](v0.0.3-report.md) に記録した。
