# Mermaid Studio（HTML試作版）

図の見本と記法サンプルを選び、左のコードと右の図を行き来して編集するブラウザ版です。MdVisualizer本体への組み込みは行っていません。

## 起動

Node.js 18以上が必要です。MermaidとCodeMirrorはvendorに同梱済みで、起動時のnpm installやインターネット接続は不要です。

```powershell
cd C:\develop\MdVisualizer
node .\dev\research\mermaid-editor\server.mjs
```

EdgeまたはChromeで http://127.0.0.1:4178/ を開きます。終了は起動した端末でCtrl+Cです。ポートを変更する場合は`$env:MERMAID_EDITOR_PORT = '4179'`を指定してください。ポート・ブラウザ・プロファイルを変えると自動保存領域も変わります。

## 基本操作

1. 左上の「新規作成」から図の基本テンプレートを選びます。全34種類（Mermaid情報を含む）を分類しています。
2. 左のコードを入力すると右の図へ反映します。「記法サンプル」で図種に合った書き方と見本を選んで挿入します。コードコメントを除く115個の記法見本があります。
3. 「開く」は.mmd/.mermaidのみ。「フォルダを開く」はサブフォルダも含めてこの拡張子だけを読み込みます。「サンプル集」で同梱データを文書一覧へ追加できます。
4. 編集はブラウザ内で行います。「保存」でコードをダウンロードします。元ファイルへの自動上書き、外部ファイル監視、Markdown読み込み、画像出力は行いません。
5. 文書一覧・編集中のコード・独自見本・お気に入り・左右幅・表示倍率をブラウザ内に自動保存します。ブラウザのサイトデータ削除やプライベートモード終了で消えるため、残したい図はファイル保存してください。

## 図の操作

| 操作 | 動作 |
|---|---|
| クリック、Ctrl+クリック、空白からドラッグ | 単一・複数・範囲選択。コード選択と双方向に連動 |
| ダブルクリック／編集 | 表示文字、対応する形・色・アイコン、項目固有の記法を編集 |
| ツールバーの追加／ノード横の＋ | 名前を入力して追加。選択ノードから接続可能なら接続 |
| Delete／削除／右クリック削除 | 前後を再接続。分岐・合流・複数削除・自己接続を扱う |
| ノードを別ノードへドラッグ | そのノードの前へ移動。Shift付きで後ろへ移動 |
| Alt付きノードドラッグ／接続ボタン | 接続追加 |
| 矢印をノードへドラッグ | 接続先変更。Shift付きなら接続元変更 |
| 矢印を選択して編集 | 接続元・接続先・ラベル・矢印記法の変更 |
| グループ化／解除 | 図種のグループ構文を生成・解除。フローチャートとarchitectureは所属変更にも対応 |
| 右クリック「コメント追加」 | コードコメントを入力。sequence/state/classでは表示注釈も追加可能 |
| ↶／↷、Ctrl+Z／Ctrl+Y | コード入力とGUI操作のUndo/Redo |
| ホイール／中ドラッグ | ポインター中心のズーム／パン |
| 全体表示／中ダブルクリック | 図全体を表示領域へ収める |

分岐・合流・循環を含む経路の並び替えは拒否します。図種にない接続やグループ化は表示しません。数値系列、文法規則などは選択項目の「記法」欄でも編集できます。

「見本に登録」はコード選択があればスニペット、なければ図全体のテンプレートを登録します。ギャラリーの☆で先頭へ移動。独自見本は名前・分類・コードを変更または削除できます。

## エラーと安全性

- エラー行を描画用コピーから除外して再試行します。元コードは残し、報告位置と除外した行を表示します。ブロック構文では除外範囲が複数行になります。
- エラー中のGUI変更はロックします。描画できない場合は最後の正常図を不一致表示付きで残します。
- 1回の描画は10秒で中止します。描画処理は別のローカルサイトのiframeへ分離し、中止後は新しい描画領域へ切り替えます。`render-*.localhost`への通信もこのPC上の同じサーバーです。
- GUIの変更候補を描画してから適用します。不正な候補や安全に変換できない複合記法は拒否し、原文を保護します。
- サーバーは127.0.0.1だけで待ち受け、このフォルダ配下だけを配信します。実行時に外部サイトへ接続しません。

## 試作版の範囲

全図種の基本サンプル・項目操作を用意していますが、Mermaidの全記法を可逆変換する汎用パーサーではありません。高度な複合接続、独自設定、複雑なブロック境界、図種固有の入れ子移動などはコード欄での編集が必要な場合があります。手書きコードを丸ごと再生成して失わないことを優先します。

GUI操作の詳細な受入範囲と検証の制約は[実装報告](mermaid-editor-imp.md)を参照してください。

### 同名ノードとグループの操作
表示名が同じでも内部IDで区別します。プレビューの「変数名を表示」でノード・グループのIDを表示できます。「置換」は現在のID、キャプション、変更後IDの表を開き、重複・漏れ・無効文字を検証して一括変更します（フローチャート）。
プラスは接続先がある場合「接続の間に差し込む」「枝分かれとして追加」を選べます。複数の接続先では差し込み対象も選択します。
グループの見出し／背景へノードをドラッグすると所属を移動できます。右クリックの「グループに追加」はID付き一覧から移動先を選択し、「上のグループから除く」は直上のグループから外します。
同名データの回帰サンプルは samples/duplicate-labels.mmd、試験は identity.test.mjs と identity-ui.test.mjs です。

### 編集画面・複製・配色
- プラスボタンはLRで右、TD/TBで下、RLで左、BTで上に表示します。追加方法はラジオボタンで選びます。グループを右クリックして追加すると、そのグループ内に項目が入ります。
- ノードのダブルクリックで文字を全選択します。形状と所属グループは縮小プレビューのカードをクリックして選びます。
- 接続線または接続ラベルをダブルクリックすると、ラベル・矢印・線色・ラベル文字色を編集できます。ラベル背景は不透明です。
- ノードの塗りつぶし・枠線・文字色は色見本と16進数で表示します。「テーマ・配色」で図全体のテーマを選び、「カスタム」で基本色を指定できます。
- 図上でノード／グループを選びCtrl+C、貼り付け先ノードを選びCtrl+Vで複製します。接続先1つなら差し込み、複数なら分岐として追加、ノード未選択なら独立したルートへ追加します。IDを再採番し、キャプション・内部接続・配色を保持します。
- 右クリックの「ルートに移動」は、選択ノードを元経路から取り除いて前後を接続し、独立したルートに移します。

### ツールバーとテンプレート登録
- ファイルツールバー: 最上段の新規作成・開く・フォルダ・保存。
- 編集ツールバー: 記法サンプル、ノード編集、グループ操作、Undo/Redo、置換、見本登録。
- プレビューツールバー: 図の右上の変数名表示、テーマ・配色、全体表示、最大化。ボタン文字を13pxへ拡大。
- フローチャートのノード編集では、表示文字の隣の「変数名（管理ID）」を変更できます。重複・使用できない文字を検証し、コード中の定義と参照を一括変更します。
- 「見本に登録」はノード選択中なら「選択ノードすべて → 記法サンプル」、未選択なら「図全体 → 図のテンプレート」が既定です。登録範囲はラジオボタンで切り替え、下のプレビューで確認できます。後者は全選択ノードと内部接続を保存し、挿入時にIDの衝突を避けます。
- フローチャートでノードを削除した後は、空白だけの行を詰めます。

### 色の既定・枝への移動・保存先
- ノード編集は文字とID、塗りつぶし・枠線・文字色、形、所属グループの順です。各色の「既定」で個別指定を解除します。グループ編集にも3色の設定があります。共有style/classは他のノードを維持して対象だけを解除します。
- 所属しない状態は「ルート」と表示し、図全体の縮小プレビューを表示します。
- 他のツリーや別枝へのドラッグは確認ダイアログを出します。キャンセル時は変更せず、反映時は元の前後をつなぎ直し、移動先の前へ挿入します。Shift付きは後へ挿入します。
- 保存通知にはブラウザー設定のダウンロード先と指定ファイル名を表示します。Webページから絶対パスは取得できないため、確定した場所はブラウザーのダウンロード一覧で確認してください。


### 右クリック操作と配色
- 「手前と入れ替え」「後ろと入れ替え」で直列ノードを移動します。
- コピー後の「前へ貼り付け」「後ろへ貼り付け」で挿入位置を選べます。Ctrl+Vは後ろへの貼り付けです。
- 1つのノードをコピーすると「書式貼り付け」で形・塗りつぶし・枠線色・文字色だけを選択ノードへ適用できます。既定色も継承します。
- 配色欄の「（既定）」は個別指定のない状態です。「既定」ボタンで個別設定を解除できます。
- テーマにはGitHub・Qiita・Zenn・Stack Overflowをイメージした独自配色も含みます。公式テーマではありません。


### 接続線とシーケンス図の編集
接続線とラベルをクリックすると接続を選択し、ダブルクリックで編集できます。線のクリック判定は見た目より広くしてあります。

シーケンス図では「参加者」「メッセージ追加」「注釈追加」「参加者グループ編集」「シーケンス配色」を使用します。参加者や注釈は図から選んで編集・削除できます。「手前と入れ替え」「後ろと入れ替え」は参加者の表示順、メッセージ選択時は時系列の順序を変更します。配色は図全体の設定です。

詳しい操作と対象範囲は[シーケンス編集の設計](mermaid-editor-sequence-design.md)を参照してください。検証用のedge-selection.mmdとsequence-editing.mmdをsamplesフォルダーに追加しています。


### シーケンス図の縦線とドラッグ
縦線にカーソルを合わせるとメッセージ追加用の＋が追従します。参加者の左右の＋は参加者追加専用です。メッセージ選択時の両端の丸は接続元・接続先変更、線中央や説明文の上下ドラッグは時系列の移動に使います。描画後の間隔はMermaidが自動調整します。

参加者間の＋は中間に1個ずつ表示します。横線の近くでは縦線の＋を隠します。横線の右クリックは編集・削除、縦線の右クリックは編集とメッセージ・自己メッセージ・注釈・フラグメント・実行区間追加です。ボックスは参加者から追加します。縦線をダブルクリックすると専用の線色編集を開きます。実行区間はクリックで選び、上下のハンドルで開始・終了位置を変更できます。フラグメントと実行区間の位置はメッセージ単位です。
