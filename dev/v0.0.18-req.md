# v0.0.18 HTML出力 要求

ユーザーがこの会話で確定した要求をv0.0.18へ集約する。独立CLIは完成とし、本体導入は後続作業。製品版番号の更新や公開を指示する文書ではない。

## 実装済み（独立CLI）

- [x] Markdownを本文・図・画像・表を含む単一HTMLとして出力する。全文・全行・全列を格納する。
- [x] 本文・表・コードはHTML、図はSVGを優先。HTML内包SVGは図単位のPNG、画像は元形式のData URLを基本とする。
- [x] フローチャートをSVG化。出力先でMarkdown・Mermaid・draw.io等の描画エンジンや元資産を不要とする。
- [x] テーマ・本文CSSを保持し、CLIから指定できる。
- [x] コード枠内の左上に言語名・指定されたファイル名を小さく表示する。
- [x] スクリプトなしstatic（既定）とスクリプトありinteractiveをCLIパラメーターで選ぶ。
- [x] interactiveではコード・表のコピーと折り返し。コピー通知は約3秒で消える。
- [x] 画面右上固定の目次、見出しジャンプ、H2以下の章開閉と全体開閉。
- [x] 図・画像の拡大表示、拡大縮小、閉じる操作とキーボード操作。
- [x] 表の列別昇順・降順・元順、全列からの部分一致絞り込み。
- [x] 表のコピーは表示中の並び順・行と見出し・集計行を対象とする。集計は全行値を維持して明記する。
- [x] 編集・AI・アプリの右クリックメニュー・Markdown／Mermaid編集連携は出力しない。
- [x] 元文書・既存HTMLの保護、失敗／中止時の安全な保存を維持する。

## 未実装（本体導入）

- [ ] Windowsデスクトップ版の印刷/PDFボタン右にHTML出力を置く。SPFxの出力ボタンは対象外。
- [ ] 保存先・ファイル名指定時に「スクリプトなし」「スクリプトあり」の2択を提示する。
- [ ] 現在の文書の未保存内容・プレビュー配色を固定して出力し、編集・タブ切替で対象を変えない。
- [ ] デスクトップで開いたSharePoint文書・認証画像・一時資産を扱う。
- [ ] 全文・全行・全列・図表示を維持し、進捗・中止・二重実行防止を接続する。
- [ ] 配布環境での生成と本体の回帰・実操作を検証する。

## 0.0.17からの引き継ぎ（2026-09-13）

0.0.17系はユーザーの指示により完了。[完了記録](history/v0.0.17/README.md)と[0.0.17.1の検証範囲](history/v0.0.17/v0.0.17.1-beta-imp.md)を参照する。以下は既存のHTML出力要求を置き換えず、保留事項・次回確認・検討候補を分けて引き継ぐ。

### 公開・受入の保留

- SPFxのsppkg生成・テストは実施済みだが、App Catalogアップロードと展開はユーザー指示で保留。再開指示時に認証と対象版を確認し、古い成果物をそのまま公開しない。
- 0.0.17 betaのZIP・MSIX・App Installerは公開済み。0.0.17.1追加修正の成果物公開とインストール確認は未実施。次回リリースでは修正を含めた対象版で再生成・検証する。今回の文書更新では公開しない。
- draw.io固有の実画面再操作、実接続AI送信・画像生成・PNG採用3方式は0.0.17.1で再実施していない。次に当該機能を変更するときは、既存の自動テストに加えて対象経路を確認する。PNG編集は実装済みであり、未実装機能として扱わない。

### 維持する回帰確認

- 閲覧のみのレンダリング差分、基準・ストレージ・採用結果の3列、可変境界、構文を壊して修復した際の即時プレビュー復旧。
- AI履歴保存エラーは再保存成功だけでなく、問題添付の除去や保存対象消滅でも解除。同じ図からの新規会話、非同期処理中の会話切替、送信後の添付解除を維持する。
- 保存・再読込後のスクロールと折畳復元、H1除外、選択テキスト取り込み、Markdown／プレーンコピー、ALT直接編集とUndoを維持する。

### 検討候補（次版での実装確約ではない）

- ChatGPT API、Claude CLI／API、Copilot CLI、Copilot Chat CLIは未実装表示の選択候補。Codex CLI以外の接続実装は別途範囲を決める。
- 既存のdevelop／verify／releaseスキルを優先し、版完了時の資料移動・リンク修正・引き継ぎを既存スキルへ追加する必要性を検討する。重複する新規スキルは増やさない。
- ボタン共通化の静的検査は既存のものを維持する。Markdownローカルリンクと版・ブランチ表記、AIメニューの対象種別を反復点検する処理は、既存入口へ統合可能か調査する。文字列一致だけで実動作を保証せず、差分・会話の状態遷移は回帰テストで検証する。
- SPFxとデスクトップが共用する依存関係のインストール／ビルドは競合を避けて順次実行する。サンドボックスのコマンド起動失敗は製品不具合と区別する。

Mermaidエディタ研究の別ブランチは維持する。文書整理中に別作業で行われた0.0.18への研究マージ（509496c）は保持し、この引き継ぎでは研究コードを変更しない。
