# 爆速 Markdown Viewer v0.0.4 要求定義書

作成日: 2026-07-30  
ステータス: **既存要件実装済み・追加要件は計画レビュー待ち**

## 1. 目的

プレゼンの深い階層を少ないページで自然に閲覧できるようにし、見出しツリーと
ブラウザー型操作履歴を追加する。Mermaidの再利用と画像キャンバス拡張にも対応する。

## 2. 実装済

### 2.1 再帰的な子孫見出し統合

* 単一の子→孫→曾孫と続く場合、統合後ページ全体の本文が設定行数以内の間は再帰的に同一ページへ表示する
* 分岐または累計行数超過の位置で統合を止め、下位見出し一覧を表示する
* 既定の設定値はMarkdownソース上の論理行数10行とする

### 2.2 プレゼン目次

* 目次トグルで文書全体の見出しツリーを左側へ表示する
* 現在ページに対応する見出しを太字または選択状態で示す
* 十分な左右余白がある場合、本文幅を縮めず、目次と本文を一体として左右中央へ配置する
* 余白が不足する場合は本文上へ重なるドロワー表示とする
* 目次項目をクリックして移動でき、その移動を操作履歴へ記録する

### 2.3 戻る・進む

* マウス第4／第5ボタンと `Alt+Left`／`Alt+Right` に対応する
* ウィンドウ単位・起動中のみの履歴とする
* アクティブタブ、スクロール位置、プレゼンページ、画像／SVG／Mermaidプレビュー、
  目次・パンくず・子見出し・ハイパーリンクからの移動を記録する
* 戻る操作で新規タブ自体は閉じず、直前のタブ・状態を復元する
* クロップ適用等のファイル書換えは履歴で取り消さない
* 新しい操作後はforward履歴を破棄する

### 2.4 Mermaid操作

* Mermaidブロックと拡大プレビューに図／コード切替を置く
* Mermaidコードをテキストとしてコピーできる
* 描画済み図をPNG画像としてコピーできる
* 描画済みSVGをSVG画像データとしてコピーできる
* Copy後にボタンへフォーカスを残さない

### 2.5 クロップとキャンバス拡張

* 選択枠を元画像の上下左右外側へ広げ、余白を追加できる
* 背景は透明、白、黒、自動から選択できる
* 透明はアルファ対応形式だけ選択可能とし、元ファイル形式を暗黙変換しない
* 自動背景は画像外周を軽量にサンプリングし、最頻色に近い代表色を使用する
* 既存バックアップ、競合寸法検出、復元機能を維持する

### 2.6 画像ギャラリーと使用箇所

実装完了: `ea2eb2a`（自動テスト・本番フロントエンドビルド確認済み）

* 同一画像が使用されている文書の他の部分について確認する手段を追加する
* 通常表示へギャラリーパネルを追加し、トグル表示できるようにする
* 画像ファイル単位でまとめて使用回数を表示し、展開すると文書内の各使用箇所へジャンプできる
* プレゼン表示にはギャラリーを表示しない
* 狭い画面では本文上へ重なるドロワー表示とする

### 2.7 ファイル名・キャプション

実装完了（自動テスト・Rustテスト・本番フロントエンドビルド確認済み）

* 画像のファイル名とキャプションを設定できる
* ファイル名変更時は実画像ファイルをリネームし、対象Markdownがあるフォルダー以下の
  全Markdownファイルに含まれる参照を更新する
* Markdown画像のalt文字列を使用箇所ごとのキャプションとして編集し、画像下へ表示する
* UTF-8 BOM、UTF-16、Shift_JISと改行形式を保持し、複数文書の更新失敗時はロールバックする

### 2.8 外部画像アプリ

* 文書用と画像用の外部アプリを設定画面で分けて管理する
* 画像プレビューに既定アプリの直接ボタンと「その他」メニューを表示する
* 旧設定は文書用へ移行し、画像用の既定アプリとしてペイントを追加する

### 2.9 画像余白プリセット

* A4横で見やすい設定幅まで左右へ均等な余白をワンクリックで追加する
* 既定幅は3508pxで、元画像が設定幅以上なら適用しない
* 余白色は白、灰、透明から選べる
* 既定32pxの同量余白を上下左右へ追加できる

### 2.10 画像注釈とサイズ指定スタンプ

* 赤／黒等の枠、単色／ぼかし／モザイクのマスク、文字ラベルを追加できる
* 幅、高さ、線幅等を指定し、図形をマウスへ追従させてクリックで配置する
* ホイールで縦横比を維持して拡縮し、配置後の再選択と再編集に対応する
* Undo、Redo、Delete、Enter、Escに対応する
* 適用時は元画像形式へ安全に保存し、既存のバックアップ／復元を利用する
* 編集中の外部変更では「外部変更を読み込む／編集中の内容を維持」を表示する

## 3. 未実装（2026-07-30追加）

### 3.1 全レイアウト共通の目次

* 目次機能をプレゼン以外の全レイアウトでも利用できるようにする
* 現在位置を強調し、項目から本文の見出しへ移動できるようにする

### 3.2 ショートカット

* `Ctrl+;` でも表示を1段階拡大できるようにする
* ステータスバーの設定ボタン左へ同じ大きさの「？」ボタンを追加する
* 「？」または `Ctrl+?` でショートカット一覧をポップアップ表示する

### 3.3 プレゼン履歴の安定化

* プレゼン表示でマウスの戻るボタンを押した際、2見出し間を往復し続けないようにする

## 4. 受入基準

* 単一子孫の累計9／10／11行、途中分岐、深い階層でページ分割が決定的になる
* 目次は広い画面で本文幅を変えず中央配置され、狭い画面でドロワーになる
* パンくずを含む各移動経路を戻る・進むで往復できる
* PNG／SVGコピーを対応アプリへ貼り付けられる
* PNG等へ透明余白、JPEG等へ白・黒・自動余白を追加できる
* 余白追加後も元に戻す操作が機能する
* ギャラリーで重複画像が1件へまとまり、各使用箇所へ正確にジャンプできる
* 画像リネームが対象フォルダー以下のMarkdown参照へ原子的かつ文字コードを維持して反映される
* キャプション変更が対象の画像記法だけへ反映される
* 設定した画像アプリをプレビューから起動できる
* 注釈の配置・再選択・Undo／Redo・適用・復元が一連で機能する
* A4横プリセットと四辺余白が指定ピクセル数・指定色で出力される
* 編集中の外部変更で、確認なしに編集中の内容が失われない
