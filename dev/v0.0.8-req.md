# v0.0.8 要求

## SharePoint Markdown

- `spmd:`独自プロトコルからSharePointドキュメントライブラリ上のMarkdown文書を開く。
- URI形式は`spmd://{tenant}.sharepoint.com/{server-relative-path}`とする。
- Microsoft Entra公開クライアント設定をアプリへ組み込み、利用者へクライアントIDやテナントの入力を求めない。

## 表示・操作の追加要求（2026-08-11）

### Mermaid

- Mermaidブロックの右上に、プレビューとコードを切り替える操作を表示する。
- Mermaidのコード表示にはコピー操作を用意する。
- PNG・SVGコピーなど既存のMermaid操作を維持する。
- `samples/mermaid-gallery.md`は、意図的な不正構文によって文書全体が常時エラーにならないようにする。

### 見出し

- 長い見出しにインラインコード（例: `これ`）が含まれても、通常のインライン文章として連続して折り返し、文字列・コードなどの要素ごとに行を分けない。
- 見出し内の画像は、見出し文字の高さを上限として縦横比を保って縮小する。
- 見出し内画像ではalt由来のcaptionを表示せず、通常画像用のリサイズ操作も表示しない。

### 目次

- ポインタが見出しそのものにある場合だけ、その見出しを目次のアクティブ項目にする。
- 見出し間の本文にポインタがある場合は、一つ上の見出しをアクティブ項目として扱わない。

## 受入基準

- Mermaidのプレビュー／コード切替とコピーをキーボードおよびポインタで操作できる。
- Mermaid描画エラー時またはコード固定表示でもソースをコピーできる。
- `mermaid-gallery.md`内の全Mermaidフェンスが構文検査を通る。
- インラインコードを含む長い見出しが一つの本文領域内で折り返す。
- 見出し画像の高さが`1em`以下となり、captionとリサイズハンドルが存在しない。
- 見出し間の本文から目次のアクティブ項目が解除される。
- 関連テスト、フロントエンド全テスト、TypeScript検査、Vite本番ビルドが成功する。
