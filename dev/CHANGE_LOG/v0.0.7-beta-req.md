# MarkdownViewer v0.0.7-beta 配布要求一覧

作成日: 2026-08-10

## リリース対象

- 現在のHEADが持つ機能を `v0.0.7-beta` として公開する。
- アプリケーションの数値バージョンは `0.0.7`、MSIX Package Versionは `0.0.7.0` とする。
- betaであることは配布チャネル、ファイル配置、Webページ、Gitタグで明示する。

## MSIX配布と更新

- MSIX、公開証明書、App InstallerファイルをHTTPSで配布する。
- beta版は `https://excel-chunchun.sakura.ne.jp/download/beta/` を更新元とする。
- 将来の正式版は別のApp Installer URIで配布し、beta導入端末はbeta、正式版導入端末は正式版を追従できるようにする。
- beta／正式版でPackage Identityと署名証明書を共通化する。同一端末への同時インストールは対象外とする。
- アプリ起動時に更新を確認する。更新確認・適用のために現在の起動をブロックせず、反映は次回起動でよい。

## 署名証明書

- 当面は自己署名コード署名証明書を使用する。
- 秘密鍵はWindowsの現在のユーザーの証明書ストアへ永続化し、以後のbeta／正式版ビルドで再利用する。
- 公開鍵だけをCERとして配布し、秘密鍵やパスワードをリポジトリ、Web公開領域、ログへ出力しない。

## 初回インストール用Webサイト

- `C:\develop\excel-chunchun\www\download\` に初回インストールページを作成する。
- ページからApp Installer、MSIX、CERをダウンロードできるようにする。
- beta版であること、対応OS、自己署名証明書が必要であることを明示する。
- beta版証明書の導入手順を独立したHTMLページとして用意する。
- `.msix` と `.appinstaller` をWindowsが要求するMIME typeで配信する。

## 公開

- `C:\develop\excel-chunchun\.env` のFTP設定を既存のアップロードスクリプトから利用する。
- 既存の未コミット変更へ干渉せず、`www\download` 配下だけを公開対象とする。
- FTP公開後、HTTPS応答、Content-Type、Content-Length、App Installerから参照するURIを確認する。
