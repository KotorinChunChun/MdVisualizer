# ワークスペースの配置

Desktop と HTML/PHP Web の文書ワークスペースは、利用できる機能の範囲で同じ操作の相対順序を使う。全操作の登録と名称・順序の検査は [UI_COMMAND_MATRIX.tsv](/docs/developer/ui/UI_COMMAND_MATRIX.tsv) を正本とする。コードブロック、埋め込みファイル、図、表の周辺メニューを変更するときは、まず [ブロックUI仕様](/docs/developer/ui/BLOCK_UI_SPEC.md) を確認する。

## メインツールバー

Desktop は「新規MD、開く、印刷、HTML出力、診断、再読込、保存、コード、プレビュー三択、分割方向、差分、外部操作」の順で置く。Web は「開く、印刷、HTML出力、保存、コード、プレビュー三択、分割方向、差分」の関係を維持し、右端を「下書きを削除、ファイル名、オプション開閉」の順にする。Web のファイル名はダブルクリックでブラウザー内の編集中の名前を変更できる。この名前変更はダウンロード時の名前へ反映され、サーバーへ自動保存しない。

コードは独立した ON/OFF、プレビューは「OFF、プレビュー限定、ビジュアル編集」の三択である。分割方向は「自動分割、上下分割、左右分割」で、本文レイアウトとは別に扱う。選択状態は Desktop と Web で共通のアクセント色を使い、プレビュー限定は中間色で区別する。

## プレビューとフッター

プレビューパネル上部には、見出し操作とレイアウトを置く。レイアウトは「オート、A4縦、A3縦、プレゼン、画像中心」で、Web の旧プレゼン単独ボタンは置かない。目次、検索、画像はプレビュー左端の縦ツールバーから開く。検索欄は狭幅でもオプションメニューへ移さない。

Desktop のフッターは文字コードなどの文書状態、テーマ、Auto Reload、Zoom、編集テスト、ショートカット、設定を提供する。Web は文字コードと BOM を左端に置き、右側を「テーマ、Zoom、ショートカット、設定」とする。Web のテーマ・Zoom・設定はブラウザー画面内の表示用であり、PHP のサーバーへ自動保存しない。Auto Reload と編集テストは Web に置かない。

## 実装上の注意

非対応のホスト機能は空白のボタンを作らず省略する。外部アプリ起動、フォルダー、VS Code、PowerShell 実行などは Desktop 固有である。Web のファイル操作はブラウザーの選択・ダウンロードであり、ローカルパスへの直接書き込みは行わない。
