# v0.0.12 実装計画・報告

## 状態

- 2026-08-27: ユーザー確認により仕様を確定した。
- 2026-08-27: `feature/v0.0.12`ブランチで実装を開始した。

## 既存実装の再利用方針

- CSV／TSVの`DelimitedTableBlock`にあるGUI表編集を標準Markdownテーブルへ共通化する。
- `MermaidToolbar`のコード、PNG、SVGコピーを図表共通操作へ整理し、draw.io全画面でも利用する。
- draw.ioの安全なMarkdown出現位置置換、一時資産ステージ、埋め込み／外部切替をMermaidへ一般化する。
- Mermaidの描画キュー、世代管理、状態APIを維持し、エラー描画だけを隔離する。
- 各フェーズ終了時に対象テスト、全テスト、型検査、production buildを行い、日本語メッセージで対象差分だけをコミットする。
- GUI実画面確認は5秒入力監視付き`pwsh -NoProfile -File .\scripts\run-debug-MarkdownViewer-all-smoke.ps1`を使用する。

## 実装フェーズ

### フェーズ1: 版更新、コード枠、ショートカットSVG

- 全マニフェストを0.0.12へ更新する。
- リッチコードフェンスの外側`pre`だけを明示的に無装飾化する。
- 共有ショートカット解析を、先頭修飾キー、記号キー、日本語操作名へ拡張する。

#### 実装結果

- ルート、共有コア、Tauri、SPFxの版を0.0.12へ更新した。
- リッチコードフェンス直下の専用レンダラーに限り、React Markdownが生成する外側`pre`の背景、余白、境界線を無効化した。
- ショートカット認識を「最初のキーが修飾キー」の条件へ厳密化しつつ、記号、矢印、日本語操作名、`Windows++`を扱えるようにした。
- 共有コアのビルド、対象テスト3ファイル33件、フロントエンド全104ファイル4565件、TypeScript型検査、Vite production build（2572モジュール）に成功した。
- SPFx production buildとJest 4スイート11件、`.sppkg`生成に成功した。公開やアップロードは実施していない。

### フェーズ2: 標準MarkdownテーブルGUI編集

- 位置、配置、改行コードを持つGFMテーブル出現モデルと安全な置換処理を追加する。
- CSV／TSVの表編集ダイアログを共通コンポーネントへ分離し、配置選択を追加する。
- Markdownプレビューのテーブル右上へ鉛筆ボタンを配置し、ドラフト更新へ接続する。

#### 実装結果

- GFMテーブルを正確な文字範囲、元文字列、配置、改行コード、引用継続接頭辞とともに収集し、競合時には誤置換しない安全更新を実装した。
- CSV／TSVの編集UIを`TableEditorDialog`へ共通化し、標準Markdown表では列ごとの既定／左／中央／右配置を変更できるようにした。
- 標準Markdown表の右上へ鉛筆ボタンを配置し、ローカルMarkdownの通常プレビューだけで編集可能にした。読み取り専用、静的、プレゼンテーション表示ではボタンを出さない。
- セル内の未エスケープ`|`を自動エスケープし、複数行入力は`<br>`へ正規化する。CRLFと引用内テーブルの接頭辞も保持する。
- 対象テスト4ファイル17件、追加境界テストを含む最終対象2ファイル12件、全105ファイル4570件、TypeScript型検査、Vite production build（2573モジュール）に成功した。

### フェーズ3: 図表共通ヘッダー、全画面コピー、Mermaidエラーと仮編集

- 図表共通ツールバーとカード見出しを作成し、Mermaidとdraw.ioへ適用する。
- 全画面プレビューへ図種と元ソースを渡し、draw.ioでも3種類のコピーを表示する。
- 全画面Mermaidから表示切替だけを除去する。
- MermaidのエラーSVG生成を抑止し、詳細ポップアップと仮GUI編集モーダルを追加する。

### フェーズ4: Mermaid保存形式切替、外部draw.io、空キャンバス

- Mermaid用の外部参照、コードフェンス、推奨ファイル名、ステージ処理を実装する。
- `.mmd`／`.mermaid`を本文内表示する外部Mermaidブロックを追加する。
- 外部draw.ioの保存済み／一時ステージ編集経路を統一する。
- draw.io XMLの描画セル有無を判定し、空図のプレビュー高を約100pxにする。

### フェーズ5: 統合検証と記録

- 対象テスト、共有コア、全フロントエンド、Rust、SPFxを検証する。
- TypeScript型検査、デスクトップ版とSPFx版production buildを実行する。
- 規定の実画面スモークを実行し、受入基準と結果を本書と進捗管理へ記録する。
