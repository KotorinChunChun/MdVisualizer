# MarkdownViewer サンプル集

アプリの表示・回帰確認に使う入力ファイルです。

| ファイル | 用途 |
| :--- | :--- |
| `sample.md` | 検証用サンプル目次、画像クロップ、自動更新、表、コードの基本確認 |
| `image-gallery.md` | 多数のPNG／SVG、連続画像の等幅横並び、リスト・引用・表・Obsidian記法での画像表示 |
| `all-markdown.md` | 本アプリが対応するMarkdown記法の総合確認 |
| `mermaid-gallery.md` | Mermaid代表図とエラー表示の確認 |
| `local-links.md` | 相対Markdownリンクを新しいタブで開く確認 |
| `linked-document.md` | ローカルリンクの遷移先 |
| `presentation-hierarchy.md` | 階層型プレゼン、10行分割、パンくず、画像ポップアップ |
| `ui-workflow.md` | 検索結果パネル、標準目次、倍率、別窓、VS Code上位ワークスペース推定 |
| `obsidian-images.md` | Obsidian画像、画像一覧・監視、altキャプションと下罫線の配置 |
| `markdown-presentation.md` | 引用、Markdown／HTML水平線、見出し罫線、プレゼン印刷の下位見出し一覧 |
| `customization.md` | 単一サイドパネル、syntax配色、PowerShell確認実行、印刷スタイル設定 |
| `images/sample.png` | ラスター画像、クロップ、表示縮小 |
| `images/sample.svg` | SVG表示専用（編集操作なし） |

最初に`sample.md`を開くと、すべての検証用サンプルへ移動できます。v0.0.5の追加機能は
`ui-workflow.md`と`obsidian-images.md`、v0.0.6の基本表示とプレゼン印刷は
`markdown-presentation.md`、v0.0.7の設定機能は`customization.md`で確認してください。テーマ配色を確認するときは、
ダーク、ライト、GitHubを切り替え、リンク、インラインコード、表見出しを比較してください。
