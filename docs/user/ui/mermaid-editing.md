# Mermaid図のGUI編集

図の「編集」からGUI編集画面を開きます。外側の「反映」で編集結果を文書へ戻し、文書の保存操作で保存します。「キャンセル」または右上の閉じるボタンでは文書へ反映しません。編集できる範囲は文書の書込み権限に従います。

## 画面と新規作成

デスクトップ・Web・SPFxの編集画面は、表示領域の幅・高さの約95%を使います。コードとプレビューのタイトルは同じ高さです。「＋新規作成」は左側の「ドキュメント」パネルにあります。画面が狭い場合はパネルが縦に並びます。

## フローチャートのノード選択と大きさ

ノードをクリックして選択します。選択済みノードから同じ枝の別ノードをShiftクリックすると、一意にたどれる接続区間のノードを追加選択します。逆方向の区間も選択できます。別の枝、分岐・合流・循環などで一意の区間にならない場合は、以前の選択を解除してクリックしたノードだけを選択します。

四角形・角丸矩形・サブルーチン・スタジアム形の最低サイズは、図の等倍時に幅120×高さ48pxです。長い文字列では必要に応じて大きくなります。円とひし形は形の縦横比を保つため、幅・高さともに120px以上になります。プレビューのズームで見かけの大きさは変わります。

## グループの削除と階層

グループ（サブグラフ）を選択して削除すると、次の方法を選べます。

- 「グループのみ削除してノードを残す」：選択したグループの囲みを解除し、中のノードと入れ子のグループを残します。
- 「グループ配下の全ノードを含めて削除する」：配下のグループ・ノードと、それらにつながる接続を削除します。

グループの外で定義され、内部から参照されているだけのノードは削除しません。確認画面でキャンセルした場合は変更しません。確認中にコードが変わった場合は、対象を選び直してください。

選択したノードがすべてルート階層にある場合、「ルートに移動」は無効です。

## 色を既定に戻す

ノードやテーマ・配色設定の「既定に戻す」は、現在値が既定値と同じ場合は無効です。色を変更すると使用でき、戻した後は再び無効になります。既定値は選択中のテーマに従います。
