# Mermaid HTML試作版：接続選択とシーケンス編集

## 接続の識別とクリック判定
- フローチャートはSVGのDOM順を使わず、同梱MermaidのDBが返す接続ID・両端IDとソース解析結果を照合する。
- 同一両端の複数接続もMermaid接続IDで区別。ラベルも同じ接続IDで対応付ける。
- 対応が確認できない線には操作IDを付けない。推測で別の接続へ編集を反映しない。
- 元の線の前に透明な12pxの判定線を配置。ズームしても画面上の判定幅を維持し、線の見た目は変更しない。
- 線・ラベルの選択はコードの接続範囲にも連動する。コード変更時に古い接続選択を解除する。

## シーケンス図の操作設計
|対象|操作|コードへの反映|
|---|---|---|
|参加者|追加、図から選択、ダブルクリック編集、削除|participant／actor、表示文字、ID。ID変更はメッセージ・注釈・実行区間の全参照へ反映|
|参加者の順序|手前と入れ替え／後ろと入れ替え|同じbox内の参加者宣言を交換。メッセージの送信元・送信先は変更しない|
|メッセージ|ボタンまたは参加者の＋、線・ラベルを選択して編集／削除|送信元、送信先、文字、矢印、実行開始／終了。選択メッセージの前後に追加|
|メッセージの順序|手前と入れ替え／後ろと入れ替え|時系列の隣接メッセージを交換。制御ブロックと明示的activate/deactivateをまたがない|
|接続先変更|線を参加者へドラッグ。Shiftで送信元を変更。右クリックの接続先／接続元変更も使用可|対象メッセージの片端だけを更新|
|注釈|注釈追加、図から選択・編集・削除|Note over／left of／right of。2参加者にまたがる注釈も対応|
|参加者グループ|複数参加者を選びグループ化、グループ編集／解除ボタン|box、名前、背景色。box色はrgb()で保存|
|配色|シーケンス配色ボタン、各色の既定ボタン|参加者3色、ライフライン、メッセージ2色、注釈3色を図全体のthemeVariablesとして保存|

- 同じ表示名でも参加者IDで選択する。メッセージは生成SVGの両端属性・時系列・件数を照合する。
- 参加者削除時は、その参加者に関係するメッセージと注釈・実行区間を削除する。フローチャートの前後つなぎ直しは適用しない。
- 不正ID・重複ID・記法を壊す入力を拒否する。候補コードを描画検証し、失敗時は元コードを保持する。
- 個別参加者ごとの独自CSSは追加せず、配色は図全体のMermaid設定を使用する。
- loop／alt／opt／par／critical／break／rectなど既存制御ブロックは保持。新しいブロックは記法サンプルまたはコードから追加する。
- 高度な参加者型、create／destroy、linksなど専用パーサー未対応の構文を含む場合、変更系の操作を無効化してコード編集を維持する。
- 参加者の直接ドラッグによる順序変更、シーケンス専用の複製、個別要素ごとの配色は今回の対象外。実行区間の整合を壊す移動・削除は描画検証で拒否する。

## 検証用データと根拠
- samples/edge-selection.mmd：同名ノード・同名グループ・平行接続・逆向き接続。
- samples/sequence-editing.mmd：同名参加者、同名メッセージ、往復、自己接続、注釈、ループ。
- [Mermaid公式：シーケンス構文](https://mermaid.js.org/syntax/sequenceDiagram.html)
- [Mermaid公式：テーマ設定](https://mermaid.js.org/config/theming.html)
- 実装は同梱Mermaid 11.16.1のパーサーと生成SVGでも検証する。公式サイトの新しい版の機能を同梱版にあるものとして扱わない。


## 縦線を起点とする操作（追加対応）
- ライフラインを選択できるよう、透明な16pxの判定線を追加。縦線付近のカーソルにメッセージ追加用の＋を追従表示する。
- ＋で開く画面は送信元と高さに対応する挿入位置を保持。自己メッセージ以外では隣の参加者を送信先の既定にする。
- 参加者の上端・下端の左右に参加者追加専用の＋を表示。先頭の左、末尾の右、参加者間に挿入できる。人型アクターの下端もIDで識別する。
- メッセージを選ぶと両端にハンドルを表示。端点を参加者またはライフラインへドロップして送信元／送信先を変更。
- 線中央または説明文を上下へドラッグし、ガイド位置でメッセージの時系列順を変更する。端点以外のドラッグでは送信元・送信先を変更しない。
- 位置は標準Mermaidコードのイベント前後へ変換する。ピクセル座標そのものは保存せず、描画後の間隔はMermaidの自動配置に従う。
- ライフライン／メッセージの右クリックから、メッセージ、自己メッセージ、注釈、フラグメント、参加者ボックス、実行区間を追加できる。
- フラグメントは既存メッセージ・注釈の範囲を指定して囲む。loop、alt、opt、par、critical、break、rectに対応。alt／par／criticalでは追加分岐名も指定できる。
- 実行区間は参加者と開始・終了メッセージを指定しactivate／deactivateを挿入。実行区間の矛盾は従来の描画検証で拒否して元コードを保持する。
- 未対応：参加者の生成・破棄、高度な参加者型、既存フラグメントの専用編集／解除UI、要素単位の配色。これらはコード編集で扱う。
