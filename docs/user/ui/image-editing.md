# PNG・JPEG画像の編集

画像を拡大表示し、「画像編集」を選びます。PNG/JPEGでは次の画面から選択できます。

- **ラスタ編集2**: 矢印、図形、フリーハンド、文字、吹き出し、連番マーカー、モザイク、ぼかし、透かし、切り抜き、サイズ変更などを備えた画像注釈画面。
- **ラスタ編集1**: 従来の注釈、自由描画、塗りつぶし、消去、回転・反転等の編集画面。既存機能は引き続き利用できます。

デスクトップのローカル画像では **ペイント** も選べます。Windowsペイントで保存した変更は画像の再読込みで反映されます。埋め込み画像・Web版・SharePointでは利用できません。

他の画像形式は従来の編集画面を使用します。画像編集の入口がない読み取り専用対象やSPFxへ、新しい入口を追加するものではありません。

## 反映とファイル保存

ラスタ編集1／2の「保存して閉じる」（外部画像）または「文書へ反映」（埋め込み画像）は、注釈を合成した画像をMdVisualizerへ戻します。デスクトップの外部PNG/JPEGは元ファイルへ保存し、既存のバックアップ・復元機能を使用します。JPEGの透明部分は白背景へ合成します。埋め込み画像はMarkdown内の画像をPNGへ置換します。Web版は既存の文書・アセット更新経路を使用します。

画面内の「PNGを書き出す」「JPEGを書き出す」は別ファイルのダウンロードであり、文書への反映とは別です。「編集用保存」の`.spmz`は元画像と注釈を保持する編集用ファイルです。文書へ反映した画像は注釈が焼き込まれるため、後日注釈単位で再編集したい場合は編集用ファイルも保存してください。

「キャンセル」は変更がある場合に破棄を確認して閉じます。外部更新を検出した場合は元画像への上書きを停止し、「最新画像を読み直す」か「編集結果を別名保存」を選べます。読込み直しは現在の編集を破棄する確認を表示します。別名保存はPNGとして新しいファイルへ保存し、編集画面を保持します。保存失敗時は編集画面と編集内容を保持します。

## 制約

注釈画面内部は提供HTMLの明るい配色を保持し、外枠はアプリのテーマに従います。隔離した画面で動作するため、描画設定のlocalStorageへの永続保存は使用できません。クリップボード読書きとダウンロードの可否はホストの権限・対応状況に依存します。

## 存在しない画像から作図する

ローカルPNG/JPEGの読込みエラーにある「画像を新規作成」から、幅・高さを指定して白紙を開けます。既定は白背景800×600、各辺1〜4096pxです。ラスタ編集1・2は「保存して閉じる」を押すまでファイルを作りません。ペイントは起動時に白紙ファイルを作ります。保存先に別のファイルが現れた場合は上書きせずエラーになります。破損や読込み権限のエラーは、存在しないファイルとは区別されます。

## 図のコピーと変換

ビジュアル画面で図を右クリックし、「図としてコピー」を選ぶとビットマップとしてコピーします。拡大表示の右上「コピー」には図、画像ファイル、マークダウン、参照先の各コピーがあります。SVG・Mermaid・draw.ioでは対応するコード・ベクター・ビットマップ・図ファイルのコピーを選べます。ブラウザーではファイルコピーがダウンロードになる場合があります。

外部画像の右クリックには「埋め込みに変換」、埋め込み画像には「ファイルへ変換」があります。文書を更新できない場合は表示しません。ペイントは右上の拡大表示メニューから外し、画像編集の選択画面にまとめています。

## キャプション

コード画面の画像挿入は、選択文字がなければ空のキャプションで挿入します。ビジュアル画面のキャプションをダブルクリックすると編集できます。空欄には「キャプションを追加」を表示しますが、この案内自体は文書に保存されません。Enter／F2でも編集を開始でき、入力後はEnterで確定、Escapeで取消します。

## 読込みや起動に失敗した場合

選択画面の「再試行」で元画像を読み直すか、「画像を選び直す」で編集に使う画像を指定できます。選び直した時点では元ファイルを変更しません。新規白紙作成後にペイント起動だけ失敗した場合は、再操作で作成済みの画像を開き、重複作成を避けます。
