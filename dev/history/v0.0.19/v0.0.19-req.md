# v0.0.19 要求メモ

> 他バージョンの実装中は本書を読まず、要求を取り込まないこと。

2026-09-21の依頼を、次回バージョン向けに記録する。現行実装との差分および解消未確認の申告症状だけを対象とする。実装着手・現行版の完了・公開を指示するものではない。Web各製品の版番号は独立管理とする。

確認根拠と、実装済みのため採録しなかった項目は[要求照合メモ](v0.0.19-request-review.md)を参照。

## Web版の上部UI

- [ ] R01: Web版のツールバー・メニューバー・タイトルバーをデスクトップアプリ版と統一する。ボタン名称、並び順、配色、デザインを完全に一致させ、必要に応じて配置を入れ替える。既存の共通化済み部分は維持し、残っている差異を対象とする。

## Mermaid GUI編集画面

- [ ] R02: ポップアップをほぼ全画面表示とし、画面の約95%を利用する。大きな画面でも固定サイズ上限によって小さい表示にならないようにする。
- [ ] R03: 右下の「キャンセル」「反映」と右上の閉じるボタンを、他の画面と同じデザインに統一する。
- [ ] R04: コードパネルとプレビューパネルのタイトルバーを同じ高さにする。
- [ ] R05: 選択したサブグラフをそのまま削除できるようにする。削除時には確認ダイアログを表示し、「グループのみ削除してノードを残す」「グループ配下の全ノードを含めて削除する」のいずれかを選べるようにする。キャンセル時は変更しない。
- [ ] R06: 画面内のバーと新規作成の配置を次のとおり整理する。
  - 上部の「Mermaid Studio」とそのバー全体を削除する。
  - 「＋新規作成」を「ドキュメント」一覧のパネルへ移動する。
  - コード・プレビューの上部にある「フローチャート」「更新済み」などのバー全体を削除する。
  - 下部の「ホイールズーム、中ドラッグ移動、中ダブルクリック全体表示」「コードと図を連動」のバー全体を削除する。
- [ ] R07: ノード編集画面・設定変更画面の現在値が既定値と同じ場合は、「既定に戻す」をグレーアウトして押せなくする。
- [ ] R08: 四角形・角丸矩形・サブルーチンなどのノードの基本サイズを統一する。短いテキストでも表示が揃う最低サイズを保証し、テキスト量によって必要以上に小さくならないようにする。
- [ ] R09: Shiftキーを押しながらノードを選択すると、同じ枝の区間内のノードをまとめて追加選択する。異なる枝を選択した場合は、それまでの選択を解除して新規選択とする。
- [ ] R10: すでにルート階層にあるノードでは「ルートへ移動」（現行表記「ルートに移動」）をグレーアウトして押せなくする。

## Markdownの埋め込み・参照ファイル

- [ ] R11: 埋め込みコードの箇所でF2を押したとき、Markdown本体ではなく、その箇所の埋め込み対象ファイルを改名する。
- [ ] R12: 埋め込みコード・画像の右クリックメニューにも、埋め込みと外部ファイル参照を切り替える選択肢を追加する。
- [ ] R13: 「埋め込み画像があると信じられないくらい重くなる」という申告を調査し、残っている性能問題を解消する。既存の画像読込修正だけで解消済みとは扱わず、読込・編集・スクロール・コードとプレビューの連動のどこで遅くなるかを確認する。測定方法は[性能回帰測定](/docs/developer/testing/06-performance-regression.md)に従う。
- [ ] R14: 「未保存だと埋め込み画像をファイルに変換できない」という制約を解消する。保存先未確定の新規文書と、保存済み文書に未保存の追加・変更がある場合を区別して確認し、未保存の内容を失わずに変換できるようにする。
