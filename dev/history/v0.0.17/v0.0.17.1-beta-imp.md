# v0.0.17.1-beta 実施計画

状態: 実装・統合検証完了。ブランチ feature/v0.0.17（統合済み）。公開は対象外。
要求の根拠: この会話の0.0.17.1 beta修正指示。要求原文をAIの提案で上書きしない。
対象: Windowsデスクトップ。SPFxの外部公開は前回指示に従い保留。共有core変更の互換性は検証する。

## 調査結果と表示意図

- src/components/DocumentDiffWorkspace.tsx は閲覧のみでもコード列を表示し、プレビューはopen未指定のdetailsに入れている。MarkdownPreviewにはmermaidMode="always-code"が渡され、図の比較閲覧を妨げる。styles/document-diff.cssもプレビューを最大35%に制限する。
- 比較基準のopenedContentは、読込／保存時の元本文。保存先最新版storageContent、編集中editingContentとの3-way比較で、外部変更と自分の変更を判別するために必要。ユーザーの追加指示により、3-wayでは基準・ストレージ最新版・採用結果を横3列に並べ、下のプレビューも対応する3列を表示する。2-wayではストレージと採用結果の2列とする。
- App.tsxのプレビューAI入口はchangeEditorMode("split")を明示呼出し。AIパネルはavailableとgetSnapshot/applyProposalが編集画面に依存。切替だけを削除すると送信と採用が壊れるため、文書操作を共通化する。
- CodexPanel.tsxの履歴保存は失敗時に共通errorを設定し、成功時に解除しない。同じselectionKeyの再操作を無視する処理もあり、新規会話の無反応の原因候補。画像生成、履歴復元との非同期競合は再現試験で確定する。
- PreviewContextMenuとuseConsultationMenuにコピーが分散。後者は元Markdownをコピーする単一項目で、捕捉順により従来メニューと競合する。コピー取得とメニューを統合する。
- packages/markdown-core/src/shortcutKeys.tsはインライン文字12、キー間gap4に+を描く。styles/app.cssはSVG全体を1.65emへ縮小する。文字指定だけでなく実表示寸法と区切り幅を修正する。
- サンドボックス内のコマンドは一部1909で起動できないため、承認済みの通常環境のpwshで実装・検証を継続。アプリ内コマンドの不具合とは扱わない。

## 仕様案と要求対応

### P1 差分の比較閲覧復旧（最優先）

対象: DocumentDiffWorkspace.tsx、document-diff.css、App.tsx、既存差分テスト。
- 閲覧のみ: コードではなく、比較する左右のレンダリング結果を初期表示。Mermaid、draw.io、SVG、PNG、通常本文、表を描画する。読取専用比較の各ペインは編集操作を持たせない。
- 編集／閲覧: 上にコード、下に対応するプレビューを常時表示。初期上下50:50、通常2列の左右も50:50。ドラッグ可能な境界を設け、最小サイズを守り、画面幅変更後も操作できる。3-way時は3列を等分し、外部変更の判別と採用を維持する。
- 編集のみの既存コード比較、行採否、Undo/Redo、未解決競合の保存防止は保持。
- 差分ボタンのaria-pressedと実際の差分状態を一致させ、共通ボタンの選択色で点灯する。遅延読込・失敗・解除・タブ切替も検証。
- 3-wayの比較基準は左列として表示し、ストレージ・採用結果との関係を明記。元データの保存安全性を維持。
受入: 閲覧だけで前後の図を並べて確認できる。編集後即時更新、構文破壊時エラー表示と修復後復旧。分割変更で片側が消えず、スクロール可能。

### P2 コピー、右クリック、ショートカット

対象: PreviewContextMenu.tsx、features/codex/useConsultationMenu.tsx、lib/previewContext.ts、MarkdownEditor.tsx、MarkdownPreview.tsx、ShortcutKeySvg.tsx、共有core shortcutKeys.ts、関連CSS。
- コード右クリックをUndo/Redo、切取/コピー/貼付、選択、AI操作の種類でセパレーター分け。キーボード移動・Esc・端での表示を保持。
- 閲覧プレビューの右クリックは「プレーンテキストでコピー」「マークダウンでコピー」を明示。Ctrl+Cも後者と同じ選択変換を使う。入力欄、コードエディタ、既存表エディタのコピーは奪わない。
- プレーンテキストはショートカットのdata-shortcut-sourceを意味単位として抽出し、キーごとのSVG text要素に由来する改行を除く。元文章の段落改行は残す。Ctrl + X → Ctrl + V、Ctrl + +等を検証。
- 文字の実表示サイズを現在のおよそ2倍へ調整。キーと+と次のキーが独立し、+の文字幅と左右余白を確保。矢印の既存余白を維持。通常幅・狭幅・明暗テーマ・本文行高で確認。
受入: 右クリックとCtrl+CのMarkdown出力が一致。装飾、リンク、見出し、部分選択・複数段落・ショートカットを比較。プレーンコピーだけのために全改行を削除しない。

### P3 閲覧中のAI操作と新規会話の安定化

対象: App.tsx、CodexPanel.tsx、useConsultationMenu.tsx、CodexBlockMenu.tsx、DiagramCodexAction.tsx、FileSvgCodexAction.tsx、sessions.ts、必要に応じRust codex_sessions.rs。
- 閲覧モードを維持したまま、文書ID・世代・本文・対象範囲からスナップショットと採用を実行。採用前確認を維持し、文書変更やタブ移動時は古い提案を適用しない。
- 画像の「AIで画像解説」「AIで画像から文字起こし」「AIで文字起こし（表）」「AIに画像の編集を依頼」は一段の項目から新規会話へ。実際の送信は既存の送信・初回同意フローを守る。
- 別項目「この画像をAIの送信対象に追加」で現在の会話の添付へ追加。既存指示文・対象・履歴を保持し、自動送信しない。画像関連操作の二段階メニューを廃止。
- Mermaid・draw.io・SVGは従来の対象設定を維持（解説・見た目改善／図編集。文字起こしは不要）。同じ一段メニュー原則に揃える。
- ユーザー操作ごとの識別子を導入し、同じ図・同じスキルへの再依頼も新しい操作として処理。新規会話作成後、その会話だけに図画像とコードを添付しプロンプトを設定。古い非同期処理が次の会話へ書き込まない。画像準備中・失敗・送信中を表示する。
- 保存エラーを送信／画像読込エラーから分離し、該当会話の保存再成功で解除。会話を切り替えた後の古い失敗で無関係の警告を出さない。ファイル容量と合計容量の検証差も調査。
受入: 同じ見た目改善操作を繰り返して新規会話が開く。遅い画像準備、素早い切替、保存失敗→画像修正→再保存成功を検証。会話を消さずにエラーだけ正しく解消。

### P4 AIパネルの最大化

対象: App.tsx、CodexPanel.tsx、codex.css。
- 「新しい会話を開始」のすぐ左に、×と同サイズの左向き山括弧型トグルを置く。最大化時は復元方向に変え、名前・ツールチップ・aria-pressedを設定。
- アプリ内の作業領域いっぱいへ広げる。OSのウィンドウサイズは変更しない。再押下で以前の幅と境界比率へ戻す。
- 最大化でパネルを再マウントせず、会話・入力・添付・処理・スクロールを維持。
受入: 送信中、長い会話、複数添付、狭幅で往復し、会話を初期化しない。

### P5 見出し選択とプレビュー内の直接編集

対象: MarkdownPreview.tsxと見出し描画、元ソース位置を付与する処理、App.tsxの文書更新。新規のテキスト範囲編集ヘルパーとテストを追加する。
- 見出しの折畳は三角ボタンだけ。文字のクリックやドラッグは折畳を起こさない。三角はキーボードでも操作可能にする。
- 閲覧プレビューのテキストをダブルクリックすると、その場に編集欄を出す。画像はダブルクリックでALT編集欄。閲覧モードを維持する。
- 編集単位は構造と装飾を壊さない表示テキスト範囲。強調やリンクなどの境界を越えて元Markdown全体を再生成しない。見出し記号、字下げ、箇条書き、引用、リンク先、画像URL・title・表示サイズは変更しない。
- 暫定操作: Enter確定、Esc取消。入力確定中のEnterはIME確定を優先。範囲外クリックは確定扱いとし、本文世代が変わっていた場合は適用せず編集文字列を保持して通知する。
- Markdown記号を入力しても意図しない構造にならないよう、対象構文に合わせてエスケープ。UTF-16位置、日本語、絵文字、実体参照、CRLF、同じ文字の繰返しを検証。
- Undoで一回の変更を戻せるよう文書編集履歴へ統合。変更は未保存の下書きとし、ダブルクリック確定だけでディスクへ保存しない。
- 図の内部文字は図ソース編集・AI編集の対象のまま。画像のダブルクリックは既存拡大操作と衝突させず、拡大入口を残す。権限上書込不可の文書と差分の比較元は編集させない。
受入: H1/H2、段落、リスト、引用、太字、リンク文字、インラインコード、表セル、画像ALTで、対象外の元ソースが完全一致。既存表編集やリンク移動と二重起動しない。
