# Codexによる文章の相談・書き換え

Windowsデスクトップ版の任意機能です。SPFxには含みません。通常の閲覧・編集にはCodexの導入もログインも不要です。

## 有効化

1. 利用する場合だけ[公式Codex CLI](https://github.com/openai/codex)を導入する。CLI 0.153.4で検証済み。
2. 外部のPowerShellで`codex login`を実行し、利用者自身でログインする。
3. MarkdownViewer上部の「Codex」を開く。
4. 「Codex連携を有効にする」をチェックする。MarkdownViewerはPATHを優先し、次に公式Windowsインストーラーのユーザー領域から`codex.exe`を自動検出する。
5. モデルを確認して「連携設定を保存」を押す。初期値は`gpt-5.6-luna`。

CLIを自動インストールしたり、ユーザーのCodex全体の設定を書き換えたりしません。検出できない場合は、Codexの導入後にPATHを更新してMarkdownViewerを再起動してください。モデルの利用可否・利用上限はログインしたアカウントに従います。

## 使い方

- ローカルMarkdownを開いて「Codex」を押す。閲覧のみの場合は編集／閲覧画面へ切り替わる。
- 全文が既定の対象。部分的に直す場合はエディタで文章を選択し、「選択範囲を取り込む」を押す。
- 指示を入力して「送信」またはCtrl+Enter。Enterだけなら改行する。
- 会話を続けて「もっと短く」「この表現を丁寧に」などと調整できる。選択範囲を使う場合、その周辺本文は自動送信しない。
- 変更案は大きなプレビューで現在の対象と提案内容を確認できる。「採用」を押すまで本文は変わらない。
- Codexパネル左端をドラッグするか、フォーカスして左右矢印キーを押すと幅を変更できる。上部ツールバーのCodexボタンは右端にある。
- パネル上部の「ログ」を押すと、このPCに保存した通信ログを全画面で表示する。左端の一覧から選び、中央の左半分で送信したCLI入力プロンプト、右半分で応答メッセージまたはオリジナルJSONLを切り替えて確認できる。最大件数は画面上で1〜1,000件に変更でき、既定は20件である。
- 採用後は通常の保存操作で保存する。通常のエディタではCtrl+Zで採用前へ戻せる。文書差分画面での採用後Undoは受入未完了。
- 本文の変更、文書の切替、再読み込みがあると古い変更案は適用できない。選択範囲や提案を作り直す。
- 「停止」で生成を止める。停止後に到着した回答は採用できない。

## 送信と履歴

対象本文・指示・このパネルの会話（過去の変更案を含む）をCodexへ送信する。パネルに対象・モデル・送信量を表示する。上限は合計120,000 UTF-8 bytes。履歴は20往復まで参照でき、上限に達したら「会話をクリア」する。

会話はパネルを閉じる、文書を切り替える、再読み込みする、アプリを終了すると消える。一方、成功したCodex CLI通信の送信プロンプトと受信データは、確認用にアプリのローカルデータ領域へ保存する。ログには送信した本文・指示・会話履歴が含まれるため、共有端末では利用後にアプリのローカルデータを適切に管理する。CLIが使用量を返した場合は送受信トークンも保存し、現在保持しているログの合計を表示する。削除済みログを含む累積使用量ではない。CLIにはephemeralを指定するが、サービス側のデータ処理条件は利用者の契約に従う。

元文書のファイルパスをCLIへ渡さず、一時作業領域で文章生成を行う。シェル・ブラウザー・プラグイン等を無効化し、元ファイルへの直接編集を許可しない。120秒でタイムアウトする。

## 初期版の範囲

ローカルMarkdownの全文／選択範囲の相談と書き換えが対象。SharePoint文書、SPFx、複数ファイルの自律編集、公式Codexアプリの会話同期、再起動をまたぐ会話保存、回答の逐次文字表示は対象外。回答は生成完了時に表示する。

変更案の表示はMarkdownViewer独自の実装である。現在の対象と提案内容を並べて、採用前に確認できる。
