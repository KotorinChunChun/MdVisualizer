# 爆速 Markdown Viewer v0.0.7 要求一覧

作成日: 2026-08-09
出典: ユーザー管理の `実装するかも.md` から移動

## 採用する要求

- 更にサイドパネルには画像一覧を表示する機能も備える。altとサムネ画像の一覧を表示して、クリックしたら当該画像までジャンプする。
- つまり、サイドパネルは「目次」「検索」「画像」の3つ。検索ボタンやテキストボックス等はサイドパネル側に移動する。
- シンタックスハイライトをカスタマイズ適用できるようにする。
- スクリプトのpwsh実行ボタンを実装する。
- 印刷用のCSSをカスタマイズできるといい。見出しの色、罫線、背景色、フォント、白黒モード

## 補足

Mermaidのコード／図切替、コードコピー、図コピーは既存実装があるため、新規要求には含めない。
