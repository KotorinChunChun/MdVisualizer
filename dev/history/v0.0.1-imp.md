# Tauri v2（Rust + React）実装設計書

## 1. 概要

### 1.1 目的

本設計書は、要求定義書「爆速 Markdown Viewer」に基づき、Tauri v2（Rust + React）で実装するためのアプリケーション設計を定義する。

本アプリは、機能を以下に絞った軽量Markdownビューアーである。

1. Markdownファイルのリアルタイム更新表示
2. Markdown内画像のクロップ編集

Markdown本文の編集、タブ、Mermaid、検索、テーマ切り替え、見出し折りたたみ等は実装しない。

### 1.2 採用技術

| 領域 | 技術 |
|---|---|
| デスクトップ基盤 | Tauri v2 |
| ネイティブ処理 | Rust |
| フロントエンド | React + TypeScript |
| ビルドツール | Vite |
| Markdown描画 | react-markdown |
| Markdown拡張 | remark-gfm |
| HTML安全化 | rehype-sanitize |
| ファイル監視 | Rust notify crate |
| 画像処理 | Rust image crate |
| 状態管理 | React useState / useReducer |
| スタイリング | CSS Modules / Vanilla CSS |
