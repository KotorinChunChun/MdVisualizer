# AIスキルの設定

MdVisualizerのAI連携では、相談や書き換えの指示を「スキル」として登録できます。スキルは表示名、対象、表示場所、AIへ送る情報、動作、本文のプロンプトを一つの `SKILL.md` にまとめたものです。設定画面では既定スキルを編集できるほか、利用者独自のスキルを追加・削除・再読み込みできます。

## 保存場所と設定画面

スキルファイルはアプリ専用データ領域の `codex-skills` フォルダーに保存されます。正確な場所はOSのアプリデータ領域に依存します。設定画面の「フォルダーを開く」で現在のフォルダーを開き、「再読み込み」でディスク上の変更を読み込みます。

設定画面では、スキルごとに次を変更できます。

- 有効／無効、表示名、表示順
- 対象（通常テキスト、コードブロック、Mermaid、draw.io、SVG、PNGなどの画像）
- 右クリックメニューとブロックメニューへの表示
- AIへ送る情報（テキスト・元コード、可視化後の画像）
- 動作（相談、または修正案を作成）
- `SKILL.md` 全文

保存前の本文はスキルを切り替えても下書きとして保持されます。保存に成功した内容だけがメニューへ反映されます。構文エラーのあるファイルは保存できず、設定画面にエラーが表示されます。

## `SKILL.md` の形式

ファイルはYAMLのfrontmatterと、空行の後に続くプロンプト本文で構成します。

```markdown
---
name: example
description: 利用者向けの説明
metadata:
  mdvisualizer:
    label: メニューに表示する名前
    enabled: true
    mode: question
    inputs: [text]
    targets: [text, code]
    contextMenu: true
    blockMenu: false
    order: 100
---

対象の内容について日本語で回答してください。変更案は返さず、replacementはnullにしてください。
```

必須項目は `name`、`description`、空でないプロンプト本文です。`metadata.mdvisualizer` は省略できます。省略した属性は無効または空の既定値になります。ファイル全体は128KB以下にしてください。YAMLのaliasを含む複雑な値や、許可されていない形式は読み込みエラーになります。

`name` はスキルの識別名です。設定画面から追加したスキルはアプリが扱えるIDで保存してください。`description` は一覧や説明に使われ、`label` はメニューに表示されます。

## 対象と表示場所

`targets` は、そのスキルが扱える対象です。

| 値 | 対象 |
| --- | --- |
| `text` | 通常のMarkdownテキスト |
| `code` | 通常のコードブロック |
| `mermaid` | Mermaid図 |
| `drawio` | draw.io図 |
| `svg` | SVG図またはSVG画像 |
| `image` | PNGなどのラスタ画像 |

`contextTargets` は右クリックメニュー、`blockTargets` は図やコードブロックのメニューに表示する対象です。これらを指定した場合は、`contextMenu`／`blockMenu` と `targets` よりも個別配列が優先されます。個別配列を指定していない古いファイルでは、従来の `contextMenu`／`blockMenu` と `targets` の組み合わせが使われます。

通常テキストと画像にはブロックメニューを表示しません。画像や図では、対象に `image`、`svg`、`mermaid`、`drawio` を指定し、可視化後の画像を送るスキルには `inputs: [image]` を指定します。

## 入力と動作

`inputs` には `text` と `image` を指定できます。`text` は選択範囲や図の元コードなどの対象テキスト、`image` は表示された画像です。図の解説や文字起こしでは、元コードから推測せず可視化後の画像を根拠にするため、`inputs: [image]` を使います。図の改善では、元コードと可視化後の画像の両方が必要なら `inputs: [text, image]` にします。

`mode` は次のいずれかです。

- `question`: 回答を受け取る相談。本文の変更案を適用しません。
- `selection`: 指定場所の修正案を作成する動作。提案を確認してから採用します。

プロンプト本文には、回答形式、変更を許可する範囲、判読できない内容の扱い、replacementを返すかどうかを明記してください。

## 既定スキル

初期状態では、次のスキルが登録されています。利用者が設定を保存すると、その設定が使われます。

| スキル | 主な対象と用途 |
| --- | --- |
| Codexに相談 | 通常テキスト、コードブロックの質問 |
| Codexに修正を依頼 | 通常テキスト、コードブロックの修正案 |
| Codexで画像を解説 | PNGなどの画像、SVG、Mermaid、draw.ioの可視化結果の解説 |
| 画像から文字起こし | PNGなどの画像から通常の文章を文字起こし |
| Codexで文字起こし（表） | PNGなどの画像から表をMarkdown表として文字起こし |
| Codexで見た目を改善 | SVG、Mermaid、draw.ioの配置・余白・文字サイズ・配色の改善 |
| Codexに図の編集を依頼 | SVG、Mermaid、draw.ioのコード修正 |
| Codexに画像の編集を依頼 | PNG画像の編集指示に基づく画像生成 |

画像の解説、通常の文字起こし、表の文字起こしは、画像を右クリックしたときのメニューから選びます。SVG、Mermaid、draw.ioでは既定のOCRメニューを表示せず、解説や図の改善を選びます。通常テキストには画像ブロック用のメニューを表示しません。

## スキルを追加・編集・削除する

設定画面の「スキルを追加」で新しい下書きを作成し、`SKILL.md` の属性と本文を編集して「スキルを保存」を押します。既存スキルは一覧から選び、表示名や対象別チェックボックスを変更できます。「変更を破棄」は保存済みの内容へ戻し、既定スキルには「既定に戻す」も表示されます。「スキルを削除」でユーザー領域のファイルを削除できます。

スキルファイルを外部エディターで編集した場合は「再読み込み」を押してください。既定スキルを一度削除した場合、再読み込みのたびに自動復元されることはありません。

この機能はMdVisualizerからCodex CLIへ相談や画像・図の指示を渡すためのものです。Claudeの実行機能、Claude用の設定、複数エージェントの自律実行を再現する機能ではありません。Codex CLIの導入、ログイン、利用上限は[Codex利用ガイド](codex.md)を参照してください。
