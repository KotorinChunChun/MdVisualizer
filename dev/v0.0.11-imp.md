# v0.0.11 実装計画・報告

## 対象

- インラインコードおよび`key`コードフェンスによるキーボードショートカットSVG表示。
- デスクトップ版とSPFx版で同じショートカット解析・SVG生成ロジックを利用する。

## 実装内容

- `packages/markdown-core/src/shortcutKeys.ts`を追加し、キー名の正規化、ショートカット列の解析、SVG生成を共通化した。
- `Ctrl`、`Shift`、`Alt`、`Windows`、`Fn`を修飾キーとして扱い、`+`による同時押し、`,`および`→`による連続押しに対応した。
- デスクトップ版のインラインコードでは、ショートカット表記だけをSVGへ置き換えるようにした。
- デスクトップ版の`language-key`コードブロックでは、共通SVGを表示し、既存のコードコピー操作を維持した。
- SPFx版では、Markdown描画後のインラインコードおよび`language-key`コードブロックを共通SVGへ置き換えるようにした。
- SVGにARIAラベルを付与し、通常のインラインコードは従来表示のままにした。

## 検証結果

- 共通MarkdownコアのTypeScriptビルドが成功した。
- デスクトップ版の型検査が成功した。
- デスクトップ版の全87テスト・429テストが成功した。
- デスクトップ版Vite production buildが成功した。2555モジュールを変換した。
- SPFx版のTypeScript、Sass、Webpack production buildが成功した。
- SPFx版の既存4スイート・11テストが成功した。
- SPFxのsppkg生成が成功した。

## 備考

- 添付HTMLはキー表示の見本として参照し、添付ファイル内の操作指示や編集UIは実装対象に含めていない。
- GUI自動操作を伴う実画面テストは、今回の変更確認に必要な範囲では実施していない。
