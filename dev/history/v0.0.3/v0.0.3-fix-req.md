# 爆速 Markdown Viewer v0.0.3 要求定義書

作成日: 2026-07-30  
ステータス: **実装・自動検証完了（GUI再検証は入力検知により保留）**

## 1. 目的

v0.0.3の既存機能で利用を妨げている不具合を先に解消し、画像・SVG・Mermaidの
プレビュー操作を一貫させる。設計規模の大きい新機能はv0.0.4へ分離する。

## 2. 実装済

### 2.1 ファイルを開く操作

* Markdownファイルをウィンドウへドラッグ＆ドロップしたら、そのウィンドウのタブで開く
* 複数ファイルの場合は対応するMarkdownファイルを順番に開き、最後のファイルをアクティブにする
* 既に開いている同一ローカルファイルは新規タブを作らず、既存タブをアクティブにする
* 相対表記、区切り文字、英字大小文字が異なってもWindows上の同一ファイルとして扱う

### 2.2 画像・SVG・Mermaidプレビュー

* 通常レイアウトでも、ラスター画像の1回目のクリックは拡大プレビュー、2回目でクロップ編集とする
* SVGもクリックで拡大プレビューできる。SVGは編集へ進まない
* プレビューの閉じるボタンを右上へ置き、角丸の `×` ボタンにする
* 画像はウィンドウ内へ縦横とも収まる最大倍率を初期値とし、小画像も拡大する
* 「全体表示／1:1」ボタンでfitとdot-by-dotを切り替える
* ラスター、SVG、Mermaidのプレビューをホイールで拡大縮小できる
* 画像・MermaidプレビューはEscで閉じる
* Mermaidの既定拡大も画面内へ収まる最大サイズとする
* Mermaid構文エラーが発生しても、タブやメニューを画面外へ押し出さない

### 2.3 クロップ境界の操作

* クロップ枠が画像の四辺と一致していても、画像外側を含む十分なヒット領域からハンドルを掴める

### 2.4 通知・ボタンフォーカス

* トーストは表示後1秒でフェードアウトを開始し、2秒後までに消える
* Copy操作後はボタンへフォーカスを残さず、キーボード操作を継続できる

### 2.5 プレゼン操作とサンプル

* 「前へ」「次へ」ボタンを角丸で控えめに装飾する
* `presentation-hierarchy.md` の複数子見出しを約10件に増やし、各項目へ短い本文を追加する
* `all-markdown.md` の4文字インデントコードブロックを、明確な複数行コードへ修正する

## 3. 受入基準

* ドロップ、文書内リンク、起動引数の各経路で同一ファイルのタブが重複しない
* PNG、SVG、Mermaidが初期fit、1:1、ホイール、Escで同じ操作感になる
* 通常表示のローカルラスターだけがプレビューの2回目クリックでクロップへ進む
* Mermaidの正常・構文エラー表示のどちらでもアプリ上部UIとステータスバーへ到達できる
* クロップ四辺を画像境界の外側から掴める
* トーストは2秒後にDOMから消え、Copy後のフォーカスがボタンに残らない
