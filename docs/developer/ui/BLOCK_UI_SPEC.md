# コード・図・表・埋め込みファイルの共通メニュー仕様

コードブロック、図、表、埋め込み／外部参照ファイルのメニュー変更では、最初に本書を参照する。形式別に独立した並び順を追加せず、共通コマンドの表示条件と形式別処理を変更する。

- [共通UI定義表](/docs/developer/ui/BLOCK_UI_DEFINITION.tsv)：レベル・共通ID・対象形式・条件・現状と目標。
- [最終配置順](/docs/developer/ui/BLOCK_UI_FINAL_ORDER.tsv)：最終形だけを配置順で表示。
- [全操作登録表](/docs/developer/ui/UI_COMMAND_MATRIX.tsv)：実装から抽出した現状の全操作。仕様への適合完了とは別に管理する。

## 確定した表示順

対象外の操作は空白を作らず省略する。ファイル名、形式名、格納形態バッジを先頭に置く。表の検索欄は全レベルでメニューへ収納しない。

| レベル | 操作の左からの順序 |
|---|---|
| 1：とても狭い | 編集 → AI▽ → 折り返し → その他 |
| 2：通常 | 編集 → AI▽ → コピー▽ → 表示内容コンボ → 区切り → 折り返し → その他 |
| 3：非常に広い | 編集 → AI▽ → コピー候補 → プレビュー → コード → 区切り → 折り返し → 列表示 → ヘッダ → スライサー → 印刷 → 格納形態切替 → PS1実行 |

編集・折り返しは対象形式で全レベル常時表示。AI▽はDesktopのみ、全レベル常時表示し、全AIコマンドをその子メニューに並べる。WebにはAI関連操作を表示しない。AIをその他メニューに収納する案は取り消した。

レベル1のその他は、コピーグループ、プレビュー／コード、表操作、印刷、格納形態切替、PS1実行の順。レベル2のその他は表操作以降を同じ順序で表示する。PowerShell実行はDesktopのPS1を対象とし、既存の実行確認を維持する。

## コピーと幅判定

すべてのコピー候補を共通コピーグループとして定義する。レベル3だけ個別展開し、レベル2はコピー▽のサブメニュー、レベル1はその他メニュー内のコピーグループに候補を直接並べる。形式に適合する候補だけを表示し、各候補には内容を説明するツールチップを設ける。

レベル3は単なる画面幅では決めず、その形式の全操作・ラベル・余白が実測で収まる場合に限る。コピー候補が多い形式で、無理に全表示へ切り替えない。

## 区切り線

コピーグループと前後のグループの間、およびプレビュー／コードの表示切替グループの後に区切りを設ける。ただし空グループは除外し、先頭・末尾・連続した区切り線は出さない。形式・ホスト・幅による省略後に判定する。

## コード編集欄の右クリックメニュー

コード編集欄の標準項目は、切り取り → コピー → 貼り付け → 区切り線 → すべて選択 → 区切り線 → 利用可能なAI操作の順とする。AI操作がない場合は、すべて選択の下に末尾の空区切り線を表示しない。「アプリの設定を変更したい」は右クリックメニューには表示せず、設定画面から利用する。ビットマップ画像・ファイルオブジェクトの貼り付け表記は、このメニューの配置とは独立して本文貼り付け仕様に従う。

## 形式と格納形態

通常コード、PS1、Mermaid、SVG、draw.io、TSV、CSV、Markdown表、ショートカット表示を対象とする。同じ形式はコードブロック・本文埋め込み・外部参照・単独ファイルでも共通の操作名と相対順序を使う。編集・コピーは形式に応じた既存処理へ接続し、保存先やホスト能力の差は表示条件で扱う。

表の列表示・ヘッダ・スライサー・検索・印刷・ページ操作・右クリック操作も定義表に含める。表編集画面内部の全操作は全操作登録表で管理する。

通常のMarkdown表にも検索・列表示・スライサー・並べ替え・範囲コピーを提供する。表示上の絞り込みと文書データは分離し、表編集では非表示の行・列も保持する。GFMのMarkdown表はヘッダ行が必須なので、ヘッダON/OFFはTSV/CSVを対象とする。表編集ダイアログは画面の95%を使い、Ctrl+Aは単一セルならセル内文字列、複数セル選択中なら表全体を選択する。

「プレビュー限定」は本文の直接編集・ドラッグ・チェック切替を制限する。文書の更新が可能なら、図表の明示的な「編集」とDesktopの「AI」は全レベルで表示する。本当の読み取り専用文書やホスト能力による制限とは分離する。図・表を未変換のコードへ戻す状態ではなく、静的HTML出力の処理とも区別する。

## 変更と検証

変更時は本書と定義表を先に確認し、必要な仕様変更を更新する。最終配置順は `python scripts/generate-block-ui-order.py` で再生成し、`--check` で更新漏れを検出する。共有正本のResponsiveToolbarと各形式の項目定義を変更し、Desktop投影とWeb/SPFxの対応を検証する。

幅判定、編集・折り返しの固定表示、WebのAI非表示、コピー候補保持、空グループ除外、メニューのキーボード操作を検証する。UI登録表の基準更新は意図した変更のレビュー後に行う。実装中の目標を現状の成功として扱わず、版別の実装報告に検証結果を残す。


## ボタンとコピー通知

折り畳み記号は表示内容コンボと同じ下向きchevronへ統一し、文字の白抜き三角は使わない。広幅で個別展開したコピー候補にも共通のボタン装飾・寸法を適用し、素のブラウザーボタンに戻さない。記号とスタイル適用は静的検査の対象とする。

ベクター／ビットマップコピー成功の通知には、それぞれ「SVGファイルとしてコピー」「ビットマップファイルとしてコピー」を付ける。実行した形式のファイルコピーに接続し、失敗時は成功通知にしない。

### SVG編集の保存形式

SVGの編集結果はdraw.ioのxmlsvg書出しを経てSVGとして保存する。応答の要求オブジェクトと要求IDを照合し、SVGを検証してから既存の保存経路へ渡す。埋め込まれた図のXMLは再編集に利用し、SVGファイルへdraw.io XML単体を保存しない。

### コピー操作の通知と選択範囲

Markdown表のCSV・TSV・Markdown・プレーンテキストコピー、およびインラインコードコピーは、クリップボード書込みの成功後に右下へ通知する。失敗時はエラー通知とし、成功扱いにしない。

見出しの文字選択をCtrl+Cでコピーするときは、見出し記号を付けず、実際に選択した表示文字列をコピーする。選択終端が次のブロックの先頭に置かれても、そのブロックに選択文字がなければコピー対象へ含めない。右クリックの「マークダウンでコピー」は引き続きMarkdown形式を明示的に選択する操作とする。

SVGコードブロックは既存のテキスト外部化、本文内SVGと外部SVGは既存のアセット変換を共通ツールバーから呼び出す。真の読み取り専用・印刷・保存中では変換操作を提供しない。

### 操作消失の防止

共有 `previewOperationPolicy` は文書更新可否と表示モードを別入力として扱う。Desktop/Webの本文直接編集は編集モードだけ、明示的なブロック編集・格納形態変換は閲覧モードでも有効とする。印刷中・保存中・プレゼン中・更新不可では更新操作を抑止する。

`previewActionContract` は実装されているコールバックから期待値を逆算せず、形式ごとの必須接続を定義する。Desktop/WebのMarkdownPreviewは開発描画時に契約を有効化し、必要な処理の欠落をエラーとして示す。静的出力・プレゼン・更新不可の表示は対象外。GFM表には格納形態変換を要求しない。Webの本文／外部SVGの汎用アセット変換も未対応として除外する。新しい形式を追加するときは契約と描画テストを一緒に更新する。

コード・TSV/CSV・Markdown表・インラインコード・図のボタンコピーは、共有 `copyOperation` の `copyWithFeedback` / `copyTextWithFeedback` を使う。非同期処理の完了後に成功を一度だけ通知し、同期例外・非同期拒否はエラー通知にする。通知内のファイルコピー操作とホストのダウンロード結果を保持する。選択文字のCtrl+Cは既存のクリップボードイベント処理を用いる。

回帰検査は操作ポリシーの状態組合せ、形式別の必須接続欠落、実コンポーネントの閲覧／編集・更新不可・幅別の操作到達性、コピー成功／失敗／完了待ちを分担する。静的なホスト配線検査だけで動作保証とはしない。

### 図の右クリックと拡大表示

図の右クリックの先頭は「図としてコピー」とし、表示図のビットマップをクリップボードへ書き込む。本文のプレーンテキストコピーとは分ける。続いてマークダウンコピー、変更可能な対象の格納形態変換（外部参照は「埋め込みに変換」、埋め込みは「ファイルへ変換」）、利用可能なAI操作の順とする。コピーは共通ID copy.bitmap、変換はstorage-switchに対応する。

拡大表示のコピー群は右上に置く。ラスター画像は図・画像ファイル・マークダウン・参照先、ベクター図はコード・ベクター・ビットマップ・対応する図ファイルを提供する。ペイントなどの外部画像アプリは拡大表示から起動せず、画像編集の選択画面へ集約する。

キャプションはダブルクリックまたはEnter／F2で編集する。文書を更新可能なら閲覧モードでも明示的なキャプション編集を提供するが、本文の直接編集は許可しない。空キャプションは編集用の案内を表示し、その案内文字自体をMarkdownへ保存しない。
