# Web版モバイル操作コマンド棚卸し

対象は v0.0.18 の現行 HEAD にある `web/src/WebApp.tsx` と、そこから表示される編集・検索・目次・PHP一時保管およびモーダルの操作である。これは折りたたみ後も同じ操作をキーボードとスクリーンリーダーから到達できることを確認するための基準台帳である。Web版の初期表示は `preview` とし、sourceへ切り替えた時に編集ツールバーを監査する。コマンドの固定値監査は `web/tests/mobile-commands.mjs` から実行する。

## 現在の折りたたみ境界

`WebApp` はすでに次の3つをネイティブ `details/summary` で囲んでいる。

| セレクター | summary | 展開先 | 条件 |
| --- | --- | --- | --- |
| `.web-app-menu` | `メニュー` | `.web-menu-items` | 常時 |
| `.web-options` | `オプション` | `.web-options-items` | 常時 |
| `.web-remote-storage` | `暗号化一時保管` | `RemoteStorage` | PHPホスト (`hosted`) のときだけ |

モバイル対応で追加・再配置する場合も、summary は `button` の代替表示だけにせず、`details` の開閉、`summary` から最初の操作、閉じた後の summary へフォーカスを戻す挙動を保つ。`WebApp` の `header` にある表示切替はメニューの外側に残る。

## 操作台帳

### プレビュー目次（目次操作は可変数）

出典: `src/components/DocumentToc.tsx:84-183`。

| 操作 | 条件・動作 | 到達先 |
| --- | --- | --- |
| ☰ 目次 | `aria-expanded` を反転 | プレビュー内 `.document-toc-toggle` |
| 見出しボタン | 見出しごとに生成。クリックでソース行へジャンプし目次を閉じる | `目次` → `文書全体の目次` → 見出しボタン |
| 見出し並べ替え | `onMove` がある場合だけ。同階層でPointer drag、Alt+↑/↓ | 各見出しボタン。移動結果は `aria-live` で通知 |

### PHP暗号化一時保管（PHPホスト時のみ）

出典: `web/src/RemoteStorage.tsx:36-39`。外側の `<details class="web-remote-storage">` は `WebApp` の `hosted` が真のときだけ生成される。

| 状態 | 操作 | 到達先 |
| --- | --- | --- |
| 未ログイン・providerあり | `Googleでサインイン` / `Microsoftでサインイン`（provider値に応じたリンク） | `暗号化一時保管` → サインインリンク |
| 未ログイン・providerなし | `サインイン設定は準備中です。` | 操作なし |
| ログイン済み | `現在の文書と画像を一時保管` | 同じ保管セクション。storage unavailable またはbusy時はdisabled |
| ログイン済み | `サインアウト` | 同じ保管セクション。busy時はdisabled |
| 保管項目ごと | `復号して開く` | 各項目の行。busy時はdisabled。パスワード入力後、未保存確認を経て開く |
| 保管項目ごと | `削除` | 各項目の行。確認後に削除。busy時はdisabled |

storage unavailable時は保管ボタンを無効にし、編集・ダウンロードが利用可能である説明を残す。保管項目の名前と有効期限も各行の操作名と同じフォーカス順で保持する。

## 別画面・モーダルへ移った後の操作

メニューから開いたUIも、モバイルの折りたたみで操作を失わない対象とする。

| 画面 | 操作の全体 | 主な到達先 |
| --- | --- | --- |
| HTML出力 | ファイル名、`スクリプトなし`、`スクリプトあり`、`キャンセル`（実行中は`中止`）、`HTMLを出力` | ダイアログ内。Enterでも出力 |
| Diff | `比較を閉じる`、`元に戻す`、`やり直す`、条件付き`最新版を再確認`、条件付き`採用結果を保存`、変更行ごとの`ストレージ側…を採用` / `自分側…を採用` | `差分比較` → ヘッダー → 行採用ボタン |
| プレゼン | `印刷`、`プレゼンを終了`、見出し階層のbreadcrumb、下位見出し、`← 前へ`、`次へ →` | `プレゼンテーション` の上部・本文・フッター |
| メディア拡大 | 条件付き`クロップ`、条件付き`画像編集`、条件付き`同フォルダのファイルへ変換` / `埋め込みへ変換`、条件付き`画像情報`、`1:1表示` / `全体表示`、`拡大表示を閉じる` | `role="dialog"` のメディアツールバー |

Diffの採用ボタンは変更行、比較対象の存在、保存中、編集可否によって生成・disabledが変わる。メディアの画像編集・変換・画像情報はprops条件付きで、ラベルの動的分岐を固定ラベルへ置換しない。

## モバイル実装側への連携メモ

`/root/mobile_layout` は次の既存セレクターを基準に構造を組むこと。新しい視覚上のグループを作る場合も、操作の意味を持つ名前と `aria-controls` / `aria-expanded` の対応を維持する。

```text
.web-app > header
  .web-view-selector
  .web-app-menu > summary + .web-menu-items
.web-app > nav
  .web-options > summary + .web-options-items
.markdown-editor__toolbar-details > summary（書式）
.markdown-editor__toolbar[role=toolbar]
.web-search .search-bar[role=search]
.web-preview-toc .document-toc-root
.web-remote-storage > summary + .remote-storage   (hosted only)
```

折りたたみの展開領域はDOMから削除せず、閉じているときだけ非表示にする。tab順は「表示 → メニューsummary → オプションsummary → 編集ツールバーの`書式`summary → プレビュー目次 → PHP保管summary」の順を基本とし、展開時はsummary直後へフォーカスを移す。ポータルのDiff、プレゼン、ダイアログ、メディアは各自の閉じる操作へ戻れることを受入条件にする。

## 集計

- WebApp直下: メニュー7操作（本文のみ保存は資産あり時）、オプション4操作、表示select 1。
- Markdown編集: 書式17 + 折畳/展開/保存 = 20個の可視ボタン（`TOOLBAR_ACTIONS` 17個を含む）。現行にoverflowボタンはない。
- 検索: 設定3、前後移動2、閉じる1。
- 目次: トグル1、閉じる2、見出しジャンプと条件付き移動は文書依存。
- PHP保管: providerリンクは設定依存、ログイン後は保管・サインアウト・項目ごとの復号/削除。
- 別画面・モーダル: HTML出力、Diff、プレゼン、メディアを合わせて条件付き分岐を含む多数の操作を保持する。

注: 受入テストでは表示名とtitle/aria-labelの全値を個別に照合する。保存ボタンだけtitle/aria-labelを持たず、表示文言（`保存` / `保存中…`）とdisabled条件を照合する。
