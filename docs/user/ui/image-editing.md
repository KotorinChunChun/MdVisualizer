# PNG・JPEG画像の編集

画像を拡大表示し、「画像編集」を選びます。PNG/JPEGでは次の画面から選択できます。

- **画像編集2**: 矢印、図形、フリーハンド、文字、吹き出し、連番マーカー、モザイク、ぼかし、透かし、切り抜き、サイズ変更などを備えた画像注釈画面。
- **画像編集1**: 従来の注釈、自由描画、塗りつぶし、消去、回転・反転等の編集画面。既存機能は引き続き利用できます。

デスクトップのローカル画像では **ペイント** も選べます。Windowsペイントで保存した変更は画像の再読込みで反映されます。埋め込み画像・Web版・SharePointでは利用できません。

他の画像形式は従来の編集画面を使用します。画像編集の入口がない読み取り専用対象やSPFxへ、新しい入口を追加するものではありません。

## 反映とファイル保存

RasterEditor2画面外枠の「反映」は、注釈を合成した画像をMdVisualizerへ戻します。デスクトップの外部PNG/JPEGは元ファイルへ保存し、既存のバックアップ・復元機能を使用します。JPEGの透明部分は白背景へ合成します。埋め込み画像はMarkdown内の画像をPNGへ置換します。Web版は既存の文書・アセット更新経路を使用します。

画面内の「PNG保存」「JPEG保存」は別ファイルのダウンロードであり、文書への反映とは別です。「編集用保存」の`.spmz`は元画像と注釈を保持する編集用ファイルです。文書へ反映した画像は注釈が焼き込まれるため、後日注釈単位で再編集したい場合は編集用ファイルも保存してください。

「キャンセル」は反映せずに閉じます。画面が開いている間に外部画像の更新を検出した場合は反映できません。キャンセルして最新画像を開き直してください。保存失敗時は編集画面と編集内容を保持します。

## 制約

注釈画面内部は提供HTMLの明るい配色を保持し、外枠はアプリのテーマに従います。隔離した画面で動作するため、描画設定のlocalStorageへの永続保存は使用できません。クリップボード読書きとダウンロードの可否はホストの権限・対応状況に依存します。

## 存在しない画像から作図する

ローカルPNG/JPEGの読込みエラーにある「画像を新規作成」から、幅・高さを指定して白紙を開けます。既定は白背景800×600、各辺1〜4096pxです。画像編集1・2は適用するまでファイルを作りません。ペイントは起動時に白紙ファイルを作ります。保存先に別のファイルが現れた場合は上書きせずエラーになります。破損や読込み権限のエラーは、存在しないファイルとは区別されます。
